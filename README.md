# twob2tkit 1.9.21

Minecraft 26.1.2 Fabric 客户端 Mod，提供采矿、采集、投影建造、巡航和生存辅助。不同功能通过普通游戏交互执行；部分功能会协调已安装的 Meteor 或 Litematica Printer。

## 安装

把 `twob2tkit-1.9.21.jar` 和适用于 Minecraft 26.1.2 的 Fabric API 放入 `.minecraft/mods`。它可以和 Meteor 同时使用，不需要 Meteor Addon API，服务器也不需要安装任何 Mod。

## 使用

进入服务器并开启你平时使用的飞行功能，然后输入：

```text
/twob2tkit start <目标X> <目标Z> <巡航Y>
```

例如：

```text
/twob2tkit start 100000 -250000 200
```

按 `U` 或输入 `/twob2tkit gui` 打开界面。顶部是七个分类：**首页 / 挖掘 / 出行 / 生产 / 仓储 / 保护 / 设置**，支持全局搜索和常用功能。

- 挖掘：区域挖、自动找矿、向前/向下挖、路线与安全设置
- 出行：巡航、地点收藏、风景预加载、结构与死亡点
- 生产：自动砍树、种田、喂养、钓鱼、混凝土制作、投影建造、技能库
- 仓储：仓库记录、行动清单、配方指南
- 保护：自动保护、围箱、生存提醒、治疗物资与白名单
- 设置：通用设置、按键、运行信息

技能库入口为 **U → 生产 → 技能库**。本地记录器负责发布技能目录；页面显示所有技能的最新版本，支持搜索、状态筛选、详情和自动刷新。1.9.21 修复 HMCL 改写 Java `user.home` 时读取不到目录的问题。记录器安装与验收规则见 [companion-skills/README.md](companion-skills/README.md)。

事件监督器见 [companion/README.md](companion/README.md)，混凝土制作见 [docs/concrete-maker.md](docs/concrete-maker.md)，放置节奏见 [docs/placement-speed.md](docs/placement-speed.md)。

从 1.6.9 开始，稳定核心与盾构/自动找矿运行引擎分开。1.6.10 修正了固定加载器中盾构移动输入晚于 Minecraft 玩家输入采样的问题。1.6.11 增加自动喂养。1.6.12 在升空被头顶挡住时会保持飞行并挖开挡路方块。1.6.13 增加自动种田。1.6.14 增加自动挖树。1.6.15 增加世界种子探测。1.6.16 让配方书增强在背包 2×2 里也能列出末影箱等 3×3 配方。1.6.17 增加下界基岩顶：珍珠上顶 + Y129 巡航 + 主世界坐标÷8，升级后需完整重启一次。之后只改盾构、找矿、垂直寻路等运行逻辑时，可把新的 `twob2tkit-engine.jar` 放到 `.minecraft/config/twob2tkit/runtime/`，再在“设置”点击“检查并加载新版”，或输入 `/twob2tkit reload`。热加载前会先停止当前动作并释放按键；功能包缺失、损坏或要求更高版本加载器时会拒绝切换并继续使用原引擎。“恢复内置版本”可随时还原当前核心自带的运行引擎。Mixin、按键注册、Fabric 元数据及核心界面发生变化时仍需重启游戏。

每个已存地点包含名称、X、Z 和巡航高度；点击“编辑”可改数字后覆盖保存，点击“前往”就会自动升空并向该地点前进。

下界快速赶路请上**基岩顶**（Y128 以上），不要在顶下乱飞。末影之眼是找主世界要塞的，穿基岩用**末影珍珠**。巡航页有「下界顶 Y129」「主世界÷8」「珍珠上顶」：先到下界，点珍珠上顶（或开始一次 Y≥128 的巡航会自动先上顶），上去后再按飞行巡航。第三方服若禁了珍珠穿基岩，需要你自己对着基岩角疾跑丢珍珠；从顶上往下打洞回下界要用活塞+TNT，本模组不会自动拆基岩。

默认按键：

- `U` 打开 / 关闭界面（输入框打字时不会误关）
- `End` 紧急停止（界面打开时也有效）
- `G` 开始 / 停止上次保存的目标
- `B` 开关盾构机（上次用的向前挖或向下挖）
- `V` 自动围箱（默认圆石，把自己包起来）
- `N` 自动喂养（牛、羊、猪、鸡等；喂完收起饲料，减少挤成一团）
- `J` 自动种田（手里的种子认耕地，甘蔗/仙人掌等按能活的位置种）
- `K` 自动挖树（只砍带树叶的树，可补种树苗）

这些按键可在 GUI「按键」页或原版「选项 → 控制 → twob2tkit」里改绑、解绑或恢复默认。

这些指令是备用的客户端操作方式，不会发送到服务器聊天。

```text
/twob2tkit resume
/twob2tkit stop
/twob2tkit status
/twob2tkit help
```

## 安全设置

默认到达 8 格范围后自动离线。默认还会在陌生玩家进入 64 格、生命值不高于 8，或连续 30 秒无法前进时自动离线。

默认启用前方障碍绕行：客户端会在已加载区块内向前检查约 48 格，发现实体方块后选择左右临时绕行点；绕过后继续最终目标。两侧都没有安全路线时先停止，达到“卡住秒数”后按安全规则自动离线。

```text
/twob2tkit set arrival 8
/twob2tkit set disconnect-on-arrival true
/twob2tkit set player-radius 64
/twob2tkit set min-health 8
/twob2tkit set stuck-seconds 30
```

需要关闭某项保护时，把 `player-radius`、`min-health` 或 `stuck-seconds` 设为 `0`。

```text
/twob2tkit whitelist add 玩家名
/twob2tkit whitelist remove 玩家名
/twob2tkit whitelist list
```

配置保存在 `.minecraft/config/twob2tkit.json`，上次目标也会保存，重新连接后可执行 `/twob2tkit resume`。

## 冒险助手

在顶部「生电 / 保护 / 助手」标签里可以使用以下功能：

- 行动清单：选择“出门挖矿”“前往下界”或“打末影人”，持续检查背包中建议携带的工具、食物与物资。
- 生存提醒：默认提醒回血物资不足，以及进入下界后没有实际穿戴金质护甲；图腾和鞘翅耐久提醒可选。
- 最近死亡点：死亡时自动保存维度与 X / Y / Z；同维度下可以自动飞到死亡点上方，本次到达不会自动离线。
- 本地配方指南：不依赖服务器配方书，显示木板、工作台、熔炉、烟熏炉等常用配方；首次获得关键材料时可弹出提示。
- 原版配方书集成：此功能默认关闭；在“冒险助手 → 配方指南”主动勾选“启用背包与工作台配方书增强”后，本地原版配方才会加入原版配方书主网格，并沿用原版搜索、分类、网格、分页和物品提示。背包只有 2×2，原版会藏起末影箱等 3×3 配方；增强开启后这些配方仍会列出，点开会提示去工作台合成。
- 配方发现记录：自动持久记录玩家曾经拿到背包、装备栏或鼠标上的物品类型；材料用完或重新登录后仍算已经获得。首次升级到此版本时，会用当前物品、已有仓库记录和旧配方提示补充此前已获得的物品。
- 配方筛选按钮：增强启用后，搜索框右侧可循环切换“相关 / 齐料 / 全部”。“相关”按照原版生存解锁条件显示；“齐料”要求每一种必要材料都曾经获得；“全部”显示客户端自带的全部原版配方。
- 仓库记录：主动打开箱子、潜影盒或漏斗后，保存当时的位置与物品数量，最多保留最近 50 个容器。
- 自动喂养：在范围内寻找可喂的牛、羊、猪、鸡、蘑菇牛（可选山羊、兔子），自动换成对应饲料并右键。默认同时繁殖成体和催熟幼体。26.1.2 里牛羊都吃小麦，一直拿在手上它们会跟着你挤进同一格（幼体碰撞箱也改过，更容易叠模）；喂养时只在够得着时才拿出饲料，喂完立刻换走，叠在一起时会先退后一步。成体繁殖后约 5 分钟冷却。副手如果也是小麦，它们还是会跟过来。默认 `N` 开关，`End` 可中止。
- 自动种田：用手里（或背包）的农作物自动补种。小麦种子、胡萝卜、马铃薯、甜菜种子、南瓜/西瓜种子、火把花种子、瓶子草荚果认空耕地；没有耕地且勾选「先锄地」时会用锄把泥土/草方块锄好再种。甘蔗、仙人掌、竹子、地狱疣、可可豆、海带、甜浆果按原版 `canSurvive` 判断位置（甘蔗要靠水，地狱疣要灵魂沙，可可挂丛林原木侧面）。默认不往已有甘蔗上叠。走过耕地会潜行，避免踩坏。换手上的种子就会改种那种。默认 `J` 开关。
- 自动挖树：在范围内找出连着树叶的原木连通块（含红树根、下界菌柄），从树干底部往上用原版左键砍。连通超过 80 根或几乎没有树叶的当成建筑跳过。挡准星的树叶会先挖掉；可选把残留树叶也挖掉。砍完可按树种补种树苗/胚芽/真菌。有斧会自动换上。默认 `K` 开关。
- 世界种子：普通玩家没有 `/seed`。进服时服务器只发 SHA-256 哈希种子（`BiomeManager.obfuscateSeed`），哈希不可逆。1.18 以后也不能再单靠地牢地板算出种子。网上 SeedcrackerX 一类工具是：在已加载区块里认沙漠神殿、丛林神庙、沼泽小屋、雪屋、沉船、前哨、海底神殿，凑约 40 个可提升结构位 + 32 个普通结构位，搜出 48 位结构种子，再用哈希暴力 16 位高位得到完整种子。本模组会自动记下哈希种子、刷怪笼/地牢地板、能认出来的结构和探险家地图上的红叉/神殿；结构位进度会显示在「助手 → 世界种子」。位够了仍解不开时，把导出的报告交给 SeedcrackerX 2.16.0（已支持 26.1.2），或把算出的结构种子填回「试结构种子」，本地 1 秒内用哈希解开。单人世界会直接读真实种子。认不出的结构可对准后手动标记。
- 本地生存进度：服务器没有进度数据时，原版“进度”界面仍会显示一棵可拖动的横向树。它会持续记录木头、工作台、石头、铁、钻石、水桶、岩浆桶、黑曜石、下界、末影箱、末地等里程碑；钻石套、下界合金套、图腾、龙蛋和鞘翅使用原版挑战型高亮框。记录保存在本机，不向服务器伪造或提交进度。
- 盾构机：可向前挖 1×2/3×3、向下挖竖井，或选择钻石、煤、铁、金、红石等目标自动找矿。自动找矿配合 Meteor Xray：先按 `Z` 开启透视，在客户端已加载区块内按设置的水平半径、完整纵向高度分批扫描目标矿；因此人物位于较高 Y 坐标时也能发现下方钻石，又不会把整次扫描集中在一帧造成卡顿。发现后才开一条 1×2 最小通道接近目标，方向会持续对准矿石。行进中只会顺路采集玩家周围 5 格内与当前选择相同的矿石；例如选择煤矿后，不会再主动把附近铁矿当成顺路目标。远处目标会逐层锁定当前可够到的遮挡方块，每次切换方块先发送一次原版攻击点击，再持续按住挖掘；当前层挖通后前进并继续开下一层通道。矿脉向侧洞内部延伸时会靠近至服务器实际可挖距离，采完再返回主目标。高处或低处目标会逐级清理空间并挖楼梯过去；前方只是平地时先前进再升高，已有台阶时先挖头顶，确实悬空且背包有普通方块时会补临时台阶，不再因为“没有可站立方块”直接跳过。普通平路接近目标时会持续对准下一格中心；卡在一格宽通道边缘两秒后会先纠正站位并尝试清理贴身碰撞方块，六秒仍不动才跳过目标。前方缺少地板且背包有普通方块时会自动铺路；飞行开启时允许直接跨越。隔着方块连续十五秒没有任何破坏进度、阶梯无落脚点或地板持续不安全时，会在聊天中显示原因和坐标，临时跳过不可达目标并继续找矿；正常增长的破坏进度不会因为方块较硬被误判超时。未发现主目标且附近没有同种矿石时原地等待，不会退化成普通盾构机盲目直挖。遇到可见且够得着的水或岩浆，会先用背包里的深板岩圆石、圆石等普通方块封住；没有方块或放置失败会显示具体坐标并暂停。挖掘通过原版攻击点击与持续按住输入完成，不直接发送第二套破坏操作，因此可由 Meteor Auto Tool 正常切换钻石镐；停机后会重新同步真实鼠标状态。附近怪物停手交给你的自动攻击；苦力怕会举盾或自动围箱。默认 `B` 开关。
  - 挖掉指定矿石后会等待真实掉落实体、清理近处遮挡并主动走过去拾取；只追踪当前选择矿种的普通掉落和精准采集矿块，不会为了圆石等通道废料偏航。背包已满或连续五秒仍无法接触掉落物时会停下并显示掉落坐标，避免继续前进而丢下贵重矿物。
  - 向上寻路只在前方确认为可站立台阶、当前头顶与台阶上方均无碰撞方块时短按跳跃；每个台阶最多尝试两次，落回原处后停止重复跳跃并重新判定路线。飞行上升同样先检查前上方净空。
  - 自动封住水或岩浆后会保护刚放下的封堵方块，不把它重新当作开路障碍挖掉；封堵块挡住目标路线时会保留封堵、跳过该路线并寻找其它矿石。
  - 遮挡方块连续两秒没有破坏进度时会重新触发一次原版攻击，最多重试四次、十秒后才跳过。运行时每两秒向 `latest.log` 写入一条 `[twob2tkit/Borer]` 状态快照，记录人物与目标坐标、破坏阶段、准星命中、移动停滞以及前方、头顶和脚下方块，便于定位服务器或其它 Mod 中断输入的问题。
  - 向上寻路时，目标方向正前方上下两格都是实体障碍，会锁定该方向并先挖上层、再挖下层，全部清空前禁止绕到侧面起跳。人物离地和临时切换挖掘目标不会重置同一台阶的起跳次数，落回原处两次后会可靠停止，不再无限跳跃。
- 自动围箱：一键用背包里的方块把自己围起来，默认圆石。适合半空挂机、PvP 和打怪挡伤害。默认 `V` 开关，`End` 紧急停止。
  - 完整箱：锁定按下时的位置，铺 3×3 底板、两层围墙、3×3 顶盖（约 34 块）。挂机用这个。
  - 十字快围：跟着你走，只围十字底板/墙/顶（约 18 块）。打架打怪更快。
  - 围好即停，不自动补洞；可在冒险助手里勾选「围好后继续补洞」。可改成黑曜石、末影箱或任意方块 ID。顶盖会放到当前头顶上方，飞行时不用自己飞上去。
  - 只放可替换的空气/草，不拆已有方块。半空直接围，走你已开的 Meteor 隔空放置，不再要求垫脚。副手图腾不会被换掉。
- 生电机器：按 Wiki / 开荒常用流程收录 17 台，可按「刷怪 / 资源 / 农业 / 后勤」筛选。
  - 刷怪：暗室刷怪塔、刷怪笼处理房、摔落经验井、苦力怕暗室、刷线机
  - 资源：简易刷铁机、下界刷金平台、刷石机、自动熔炉组
  - 农业：甘蔗机、竹子机、南瓜西瓜机、村民作物机、剪羊毛机、村民繁殖机
  - 后勤：刷雪平台、单路物品分类器
  - 每台都有材料清单、分层俯视图和世界全息预览；背包齐料后按准星原点自动摆方块。不会破坏已有方块，发现目标格被其它方块占用或方向不符时会暂停并明确提示，太远会等你飞近，`End` 可中止。
  - 六个尚未验证完整功能的内置模板（刷线机、简易刷铁机、刷金平台、村民作物机、剪羊毛机、村民繁殖机）保留材料与全息参考，但暂不允许自动建造，避免摆出不能工作的机器。
  - 全息预览时滚轮拉远或靠近自己（2–48 格），大机器默认会先推远一点，避免糊在脸上。转准星改朝向，距离会记住。
  - 也可导入 schematic：小木斧 `//schem save` 的 `.schem`、旧版 `.schematic`、投影 `.litematic`、结构方块 `.nbt`。把文件放进 `.minecraft/config/twob2tkit/schematics`，或沿用 WorldEdit / Litematica 的 schematics 目录。导入后都可全息预览；只含可可靠还原状态的模型才允许生存自动摆放，复杂楼梯、门、方块变种等会明确标为“仅供预览”。不会拆已有方块，单次最多约 2 万块、展开体积最多 200 万格。模型里的每个水源或熔岩源都需要一只对应的桶。

“打开容器后自动补货”默认关闭。在行动清单里打开后，助手只会从你主动打开的容器中按当前行动清单快捷移动缺少的物品；已有数量足够时不会再拿。移动按整组进行，因此最后一组可能超过清单目标。它不会自动开箱、丢弃物品、把物品放回箱子或自动穿戴装备。

配方书中的本地条目只显示原版配方，不伪造服务器的配方解锁。点击条目会在工作台显示原版材料摆放提示，但不会向服务器发送本地配方编号；实际放入材料和合成结果仍由原版服务器校验。

死亡点与仓库记录保存在本地配置中。死亡点返航不会跨维度，也不会自动完成传送门切换；到达坐标上方后需要手动下降和捡取物品。

## 工作方式

1. 自动按住跳跃键升到巡航高度（过高时按潜行键下降）。
2. 默认开启「升空时挖掉头上方块」：头顶有碰撞方块导致飞不上去时，保持你已开的飞行、抬头用原版挖掘挖开（Meteor Auto Tool 可换镐）。不挖基岩、屏障、箱子、刷怪笼。连续约 10 秒没进度会跳过该格。
3. 平滑转向目标，松开垂直移动键并按住前进键。
4. 高度偏差超过 4 格时修正高度；升空过程中若长时间无法升高，按「卡住秒数」离线。
5. 到达目标范围后释放所有由本 Mod 控制的按键，然后按设置停止或离线。

不同飞行模块对跳跃/潜行键的响应可能不同。请先在安全区域用短距离目标测试。
