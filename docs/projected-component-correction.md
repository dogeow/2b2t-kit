# 邻水侦测器朝向修正

主包 2026.10.30.2 提供 `projected_component_correction_protocol=1`。此入口属于宿主动作校验，需要完整重启；引擎版本仍为 1.8.38，不需要替换引擎或 worker。

普通 `mine_block` 保留原有邻水限制。只有同时显式提供 `projected_wet_terrain=true` 和 `projected_component_correction=true` 才使用此修正模式；它仅接纳实际方块与锁定投影均为侦测器、且 facing 不同的目标。单纯 powered 脉冲差异不允许开采，不接纳投掷器、漏斗、容器、液体、空气或其它方块。

请求仍须包含 `placement_key`、原图完整 `expected_goal_state`、实际完整 `expected_state`、快捷栏 `expected_tool_slot`、六个方向完整 `expected_neighbors`（up/down/north/south/east/west）和既有材料租约、世界、版本及时间边界。必须在健康、干燥的正常生存状态使用足够耐久的镐，不能开采脚下支撑；相邻容器、熔岩、未加载或变化的邻居继续被拒绝。原有水源和含水方块保持精确校验；开采后只接受既有空气/流水的正常水更新。

此入口仅完成一次普通开采，使用原有原生序列及服务器确认。调用者要保留任何未知回执，重新观察掉落、库存和流体后，再从能产生目标朝向的可见站位进行正常放置。不能将开采回执当作重放许可，也不能用此入口处理原图脉冲状态差异。

验证：完整源码 2324 项测试通过；候选实际 JAR 在类路径首位、排除源码类后，方向修正与邻水保护共 7 项测试通过。实机验收在安装和重启后进行，不能以构建结果代替。
