# 沙子批量烧玻璃

Kit 的 `furnace_batches.load` 现在允许 `minecraft:sand` → `minecraft:glass`，与圆石烧石头、石头烧平滑石材共用现有流程。未列出的配方继续拒绝。

26.2 实际游戏 JAR 的 `data/minecraft/recipe/glass.json` 指定普通熔炼与玻璃产物；`smelts_to_glass` 物品标签包含沙子。每个沙子产一块玻璃，8块沙子可用1块煤烧完。此次只开放普通沙子。

装料前逐炉核对空炉、当前世界和菜单；先完整记录批次，再按原有原生库存事务装入实际原料和燃料。未烧完时保留原批次及炉内产物，不重复装料；完整产出与输入守恒后才收取。重连后必须重新确认世界与炉子，未知点击不得重放。

这是可热更新的脚本入口，不修改宿主、引擎、安全锁或其它熔炼规则。回归包含沙子装料、半成品保留、8块产物精确回收、完成批次不可覆盖以及非白名单配方预先拒绝。
