# 方块放置提速 · 1.9.17

仅优化放置节奏；寻路和走位实现保持不变。

- 无方块属性、无方块实体、不会下落的普通整块：最短每 8 个游戏刻一个新提案，约 0.4 秒。
- 必须等上一目标实际发出交互且收到同位置、同状态的服务器确认；原生队列未清空、暂停或防御中均不能继续。
- 楼梯、半砖、门、朝向方块、下落方块和方块实体保留 20 刻提案间隔及原来的准备动作间隔。
- 普通块服务器确认超时或出现不符状态即停止；没有安装原生安全拦截时拒绝启动。不会通过增加同时在途放置来提速。
- 暂停取消未发送的动作，已经发出的动作仍等待确认。停止后恢复临时打印间隔。

## 实测

在同一站位，保守与提速各新增 4 个白色混凝土；两组均消耗 4 个材料、没有删除或产生不匹配方块，角色位置变化 0，血量 20。连续服务器确认的间隔计算速度分别为 0.937 和 2.500 格/秒。样本较小，不能据此保证所有材质、服务器延迟或模组组合都零错误。

617 项测试通过，包括迟到回包、同帧多次调用、暂停、未发送取消、队列繁忙及复杂方块保守节奏。可复核证据在工作目录 work/placement-speed/acceptance.json。
