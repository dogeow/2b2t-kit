# 含水方块使用真实可见表面选点

现场确认有含水顶半砖上方带临时火把，另有正确楼梯完整覆盖目标。旧桶操作始终朝方块中心瞄准：会被火把、覆盖物或邻格地板挡住，甚至已经存在正常可见边缘也无法操作。

24版仅对显式 `projected_waterlog_drain` 使用实际轮廓面的采样点，逐点经过与原版桶相同的 OUTLINE / SOURCE_ONLY 射线，仍须命中原目标并处于正常射程。普通水源采集保持原路径。实体射线、使用前再次检查、唯一一次正常用桶、服务器方块和库存回执、预测退休和库存守恒均保留。完整正确楼梯仍会阻挡，不穿透或破坏它。

构造、目标范围或瞄准在桶任务赋值前失败时，提供绑定原请求与世界的 `input_sent=false` 诊断，阶段为 `before_task_assignment`。该处理不覆盖发送后的异常，也不修改任何旧未知声明。

238项相关产物测试通过：真实Slab/Torch/Stair场景覆盖中心点撞邻格、火把挡中心但边缘可见、完整覆盖拒绝、射程边界，以及预检异常处理不包含使用或任务赋值。主包变化需完整重启；实机结果另行核验。
