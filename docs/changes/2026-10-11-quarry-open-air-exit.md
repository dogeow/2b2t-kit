# 露天入口用于收尾，单块采集剩余尾料

6×6闪长岩采集得到库存14→28后超时，保留1个未知预测。旧收尾只识别清空过的竖井，没有识别已登记露天入口，于是尝试在角色当前岩顶下垂直升空，被石头阻挡。原控制器正常保持心跳和PvE防护，没有自动离线。

只读检查当前2016格发现完整的空气横移路径。先用精确旧任务编号停止并释放旧控制，确认旧进程结束且PvE防护仍在，再沿真实空气路径移回入口，升至61.76，原生安全高空防护停靠确认，28块材料保留，无挖掘和无退出游戏。原采集日志SHA与原字节保持，不重新分类未知回执。

收尾模块现在保留露天入口对应的出口候选，未知记录只提供坐标，所有移动仍需当前空气扫描和原生身体/到达确认，不提供旧挖掘信用。新增小范围三维空气寻路，保留转弯、直线段最多16格，未知导航保留回执且不重放。

为补齐五块尾料，当前新扫描发现六个可达的外侧露头[742,32..34,994..995]，均在旧未知采坑[743..748,26..35,991..996]之外。原天然单块流水线扩展支持闪长岩，登记相邻空气站位，每块仍使用普通挖掘和新掉落入包确认，四块一组后自动继续同一目标。新单块意图只检查这些新源的路线，旧区不再作为本轮候选，旧未知记录继续保留。
