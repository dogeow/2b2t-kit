# 星舰材料流程离线改进

本轮只改 Python 材料脚本，没有启动游戏、连接或探测 Simpcraft，也没有调用真实 Jev 服务。主包仍为 1.9.102、引擎仍为 1.7.67；脚本从当前 Kit 源目录调用，无需再替换 Mod 或重启。

已修复：

- 分堆原料装炉：118 个原料分为 64＋54 也能精确装满六炉，零散煤同样处理；目标槽或回执异常时不重复点击。
- 摆炉中断：确认摆好的炉子现场核对后跳过，明确未执行的交互失败可续跑；未知结果保留待核对记录。提前排除相邻炉位，避免建到一半被容器保护拦住。
- 重复制作：明细材料恢复先盘点四个材料箱，对 23 熔炉和 136 磨制安山岩仅补差额，并保留随身 64 箭。已足量时跳过工作台往返；结束时再次审计，包括 1717 白色混凝土目标。
- 熔炼续接：`prepare-smelting-bank.py --out <全新目录> --resume-from <原始熔炼目录>` 核对两轮回执。已装料不重补原料，已收取不重做深板岩瓦，存箱中断后按实际箱子＋背包总量判断。
- 回执：熔炉与仓储审计使用整体替换写入，旧恢复目录不得复用；全部历史恢复目录的未归还潜影盒都会阻止继续。

验证：158 项 Kit 离线 Python 测试、7 项明细制作任务测试、8 项熔炼续接任务测试通过。使用真实库存事务/制作规划代码与模拟菜单、库存、世界变化；没有用测试结果代替联机验收。Java 未修改，本轮未重复 Java 构建。

恢复边界：同一 world_session 中的已确认摆放、完整装料和收取步骤可以续接。真实断线换会话、部分装料、未知点击结果或潜影盒未归还，需要先做新的归属和物品核对；不会自动跨过健康安全锁或用户的离线限制。星舰实体完工仍未验证。
