# 登记工位可用砂土制泥

实机制泥时，刚放下的泥土会在选择水瓶和接近方块期间长草；
原生 `interact` 因目标块变化在普通使用之前拒绝，旧请求保持未决，不重放。
当前 26.1.2 JAR 的 `convertable_to_mud` 标签只包含泥土、砂土、缠根泥土，草方块不属于转换材料。

登记制泥工位可选择 `feedstock_item: minecraft:coarse_dirt`。
只有现版本配方确认为 2 泥土 + 2 砂砾 → 4 砂土时才自动加工，并验证每一步的库存消耗和成品增量。
完整的一次工作访问先备齐砂土材料，仍用普通水瓶、真实块转换和原生挖掘得到泥，再加工成模型要求的泥砖。
默认泥土工序保留；未知目标、变化的配方或结果仍停止，不重放。
