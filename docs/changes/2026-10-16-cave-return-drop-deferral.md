## 本次发现与修正

- 旧洞口重新验证为畅通，当前完整洞段扫描包含125块滴水石块；历史数量不计入库存。
- 原来的返程脚本按起点和出口的小包围盒扫描，漏掉唯一绕行通道。新增 `material_jobs.cave_return`，对调用者提供的完整、最多200000格洞段分段重新扫描，每次原生请求仍不超过50000格，再沿当前空气路线返回；逐段原生碰撞检查、128步上限和不挖新路的约束不变。
- 服务器已明确确认某个矿块移除，但掉落物因合并或快照时序而没有唯一实体时，原来会中断整趟采集。现在再次确认当前方块为空、无未确认动作，并核对真实库存；未收到的物品计0件、保留记录，继续采其他目标，绝不重挖原格。
- 新增 `dripstone_cave_survey` 选择实际滴水石旁的干燥自然入口。种子坐标仅作线索；入口规划拒绝液体、容器、人工结构、危险石锥和受保护目标。已实地验证新洞勘测：当前扫描4400块、314个干燥入口候选，29块自然入口已正常打开。
