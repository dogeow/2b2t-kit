# 深板岩施工与第一次校准保存

地图画中的普通深板岩带有 `axis=y` 状态。原平面规划仅接受无属性方块与专用蘑菇柄状态，因此虽已实际持有 64 块深板岩，仍判为没有可施工成品并尝试补料。现支持普通深板岩的竖直轴状态，使用已有原生轴向放置协议；缺少该协议时不生成施工候选。水平轴或额外状态仍由专用工序处理。

正常打印继续沿用原打印器的放置预测、服务器确认、局部实物扫描与背包消耗核验；没有添加第二个放置控制器或放宽窗口验收。

另一个遗漏是尚未开始首批施工时，已有完整原生实际审计却未创建平面布局。任务遇到容量问题后安全停靠，审计无法保存，下个任务便重复读取。现在可从旧缓存取出**与固定内容哈希一致的不可变模型表**，结合当前任务的原生实际审计保存新的停靠清单。旧世界实际审计、完成数和窗口回执不会被复制。继续任务仍须与同一世界、同一原生停靠租约、修订和投影范围完全匹配；手动移动、换连接、换投影不允许复用。

顶部阶段文案从“读取投影缺料清单（本次首次）”改成“校准当前连接图面”。第一次校准完成后显示“使用材料清单，按放置确认更新”，后续窗口通过既有材料账本扣减；最终全图完成仍需新原生实物审计。
