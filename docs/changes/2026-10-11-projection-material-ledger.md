# 地图画复用缺料清单

平图施工过去每批重新读取完整投影模型，并在批次前后各做一次完整实机审计。
现在同一个在线控制器只读取一次模型，复用调度器已有的完整审计作为缺料基线。
每个窗口仍须通过原生确认、局部实物扫描、实际物资消耗和掩码清除，再提交缺料增量。
更新后的材料清单写入任务的 `projection-latest.json`，并保留基线时间和最后窗口证明。
它明确标注为基线加已验证窗口，不把保存时间伪装成最新完整扫描。

重新连接启动独立任务时重新审计实物；同一控制器不跨世界复用实际缓存。
投影选择或范围变化停止复用。局部现场有外部变化仍由窗口扫描拦截，未知窗口不扣料。
材料需求归零后再次进行完整原生审计，通过后调度器才可完成，缓存本身不能宣告完工。
原生投影建造任务也有增量材料统计，但外部材料工序没有启动它，不为读取统计增加第二个动作控制器。

相关 238 项 Python 测试通过，覆盖连续两批仅读取一次模型和基线、数量扣减、旧世界和未知结果拒绝、完整验收及扫描期间的轮询重入。
源码包已安装到实际 26.1.2 游戏目录，未更换主包或重启游戏。
实机任务：`map-full-kit-material-ledger-3799-040`；本文件的代码测试不代表整幅地图已经完成。
