# 地图画粗铁近色替代

根据用户要求以接近的颜色替代粗铁、减少采矿，单独生成并加载省铁近色版。原示意图、WorldEdit 源文件和原等色 Litematic 均保留，原文件哈希核对未变。128×128 图像和北侧 128 格参考行仍为 16512 格，同一坐标、Y64、方向和尺寸。

当前 26.1.2 方块数据中，粗铁块是唯一使用地图色 ID60 的方块。粗铁普通地图 RGB 是 `#BA967E`；最近的其他地图色 ID36 是 `#B4988A`，樱花木板与白色陶瓦均使用该色。这里比较地图 RGB，不能用方块材质纹理的粉色判断地图颜色。

替代仅作用于原粗铁的 3173 个像素（19.366% 图像）。其 CIEDE2000 色差为 4.0632，全图平均为 0.7869，RGB 差为 `[-6,+2,+12]`。效果略偏灰粉，并会合并原粗铁与原白色陶瓦/樱花木板之间的细微色差；它是近色方案，不是等色方案。轮廓和其他 13211 个图像像素保持原色。

色差程序使用 sRGB/D65 转换并通过全部 34 组 [Sharma、Wu、Dalal 的 CIEDE2000 参考数据](https://hajim.rochester.edu/ece/sites/gsharma/ciede2000/)；最大误差为 0.0000495。对照图及数值报告位于 `work/live-20261004/raw-iron-color-comparison-001/`。

新文件：`outputs/map-art/yui-rawiron-cherry-v1/Yui-128x128-close-cherry-v1.litematic`（位于原 Codex 3D 工作目录）。SHA-256 为 `baae7c29098d38803730178502681357a9bf4d2d04bcec4c5b9ef7b02e45f2c6`。生成后读取 NBT 回验全部 16512 个状态及北侧参考行。

通过 Kit `projection_load` 在健康高空闲置时加载，随后 `projection_model` 逐格核对状态、属性和物品，共 16512 格。新模型内容哈希为 `0d3e07d872842a87efc9b748df6ddc6e6976af164777638b836e401e713bc8da`。加载只更改投影配置，没有修改已建方块；加载前实际全景没有粗铁块。

总需求由 3173 粗铁块改为额外 3173 樱花木板，樱花木板合计 3658。避免制造 28557 个粗铁需求。新验证文件明确记录 13211 个原 RGB 精确匹配和 3173 个近色像素，不沿用或伪造原等色方案的 16384 精确匹配声明。

施工和最终验收必须使用新模型、独立布局及验证文件。原未知操作记录继续保留，不将投影加载或预览当成实物完成。最终仍须核对全部 16512 个实物及真实地图数据。
