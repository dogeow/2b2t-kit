# 补料优先顺序与树木搜索范围

平面施工在随身可用材料用完后，会返回下一批补料目标。原补料规划按容量和材料名排序，没有传递完整材料任务已经设置的 `preferred_materials`，因此深板岩仍有缺口时选择了按字母排前的金合欢木。现在平面规划接收同一请求的顺序，补料按该顺序选择；已经携带的可用成品仍先施工，不为优先顺序重新取料。

另一个实机搜索问题是树木与地下矿产共用扫描层：树木搜索也扫描 `-60..47` 的地下。这些格子不能成为原树木分类器 `48..160` 的候选。现在树木仅扫描 `48..110` 和 `111..164`，保留原来的地表、树冠与高处树干覆盖。地下矿产、表层土方与雪地各自的范围保持其原分类需求。
