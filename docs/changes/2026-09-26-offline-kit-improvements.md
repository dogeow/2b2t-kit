# 2026-09-26 Kit 离线改进

已构建、备份并替换主包 **1.9.101** 和配套引擎 **1.7.66**。没有启动 Minecraft、登录或重连；游戏内效果需在用户明确允许后验证。

| 重点 | 本轮改动 |
|---|---|
| 效率 | 小量配料选择更少的点击；从64个材料取1个的模拟操作数从33次降至3次。保留数量、光标及服务器确认检查。 |
| 卡住 | 短暂状态停顿先有界重读；中断批次依据实际回收量续做；收尾前等待自己仍在执行的原生动作。 |
| 怪物安全 | 修复低顶或飞行失败时跳过后续近战/射箭的分支；工作继续暂停，改用地面防御，低血量仍交给原生紧急撤离。苦力怕优先级和确认击杀规则保留。 |
| Jev | 冻结决策输入，核对迟到结果；服务异常退避、有效缓存复用、预算损坏时停止请求；缓存不重复统计请求用量；限制场景大小。 |
| 日志 | Jev 诊断脱敏并限量轮换；原始事务证据保留。新增只读诊断摘要，统计耗时与失败类别；原生状态写入异常及慢快照分别限频记录。 |
| UI | 共享带“清空”的搜索组件，清空后保持输入焦点；切换分类/搜索时清理旧提示。首页仅收藏、分类搜索仅首页的行为保留。 |
| 代码 | 新增注入客户端的 InventorySession；合成与熔炼不再改写共享全局客户端。容器变化、目标被占用和迟到确认均有回归覆盖。 |
| 规范 | 增加组件分层、贡献约定及统一离线检查入口。安装器同步主包内的配套引擎、校验哈希，失败时回滚，避免新宿主混用旧引擎。 |

- `decision-runtime/diagnose.py --run <运行目录>`：有界只读摘要，不连接游戏。
- [组件边界](../../decision-runtime/ARCHITECTURE.md) 与 [贡献约定](../../CONTRIBUTING.md)。
