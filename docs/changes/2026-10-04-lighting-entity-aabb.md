# 补光实体走廊与高空详情验证

`LightingRun.move` 原来把整数扫描盒内的所有实体视为与玩家移动相交。真实 00375／region99 的扫描 `materials-160903e4df57` 完整读取 4 格，世界 46／版本 1549；牛的 AABB 最大 X 是 760990.002734，而下一段保守玩家扫掠最小 X 是 760990.15。牛最大 Y73.4 也低于目标脚位 Y73.5，因此旧门槛错误阻止了下降。

现在先验证实体观测的同世界、已知扫描范围、完整格数及一致控制版本，再逐个要求完整六个有限数值 AABB 边界、正体积以及明确实体类型／alive／hostile。与整数扫描范围矛盾、缺失、畸形或外来范围都拒绝。随后只保留与真实 start→target 的保守扫掠身体 AABB 相交的实体：水平半径 0.35、高度 1.8；仅接触边界不算体积相交。真实相交的牛仍遵守原有被动动物绕行或停止规则，不攻击、移走或伤害动物。

相同门槛用于防御后的站位重新接近，避免近旁动物造成不必要的高空绕行。放置前的完整支撑／目标列实体检查保持原范围，因为它保护实际交互列，不能缩减为玩家身体范围。每段导航仍使用 `air_only=true`，由原生 Minecraft 重新检查实际碰撞与危险；回执未知不重放。

本轮同时补严高空预检查：每个非 AIR 格都必须包含原生七个布尔字段（solid、fluid、passable、replaceable、block_entity、zombie_spawn_floor、zombie_block_light_risk）、两个 0..15 整数字段（spawn_block_light、monster_spawn_block_light_limit），以及一致风险关系。缺失 passable／replaceable 等字段或矛盾值会等待，不能当作零候选完成，也不能触发下降或产生放置信用。

离线验证含真实牛形状、三轴分离与边界接触、微小真实交叠、缺失／非有限／反向 AABB、外来或不完整扫描、站位重接近及高空详情缺失／矛盾反例。00375 原件只读调用新几何门槛返回零个相交实体；这不是区域已完成证明。修改期间没有游戏调用、安装或实机导航。
