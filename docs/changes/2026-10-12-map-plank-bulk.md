# 地图木板批量制作

地图剩余深色橡木板数量为 2140。此前 stack_recipe 只将橡木、云杉和樱花木板列入普通批量输出，深色橡木和金合欢走逐份合成。现在给这两种木板加入严格的一份同树种原木/木头到四份木板的批量入口：只接受 2/3 格配方宽度、单个原料格、同树种的普通或去皮 log/wood，以及整数 4 成品。实际配方继续来自已安装 Minecraft 26.1.2 客户端 JAR。

带 64 根原木和成品空间的回归，一次计划消耗 32 根、制作 128 块；必须同时确认原料减少 32、成品增加 128。成品出现而原料未消耗、外树种、重复格、容器原料、布尔格编号和错误产量均不接受。现有 32 轮上限、未知点击不重放和库存保护不变。
