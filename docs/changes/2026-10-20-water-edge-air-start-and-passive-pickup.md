# 水边空气路线起点与已拾取物品的观察

实机收割甘蔗时，普通拾取停靠未追上漂走的掉落物。后续新空气航点靠近物品，背包真实增加1根、原实体消失，但脚部停靠稍低触及水面，原生返回已停止而非到达。原回执保持不变，没有再次派发原collect_item或伪造到达。

新增stopped_air_pickup观察器仅允许一次snapshot：前序必须是相邻的真实snapshot，当前必须是同一世界、同一任务、同一修订号的已结算停止；前后库存与原生增量必须恰好增加那个唯一已见单件物品，原实体必须消失，全部键已释放、生命满、没有手动接管或未知原生请求。若实时事件里仍有原实体的拾取记录，必须与玩家及数量一致；短期事件已淘汰时只认可库存守恒证据，不宣称NPC收到了食物或原导航已完成。原生snapshot无phase时按其connected/id协议判断，不臆造phase。

普通已停止空气路线的观察仅额外接受飞行中不超过0.1格的向下落稳、最多0.05格平面变化且库存完全不变。它仍只发snapshot，禁止重复路线。

局部规划器不再把水面上方较高的悬停先下降归一化到grid+.1：若下面是流体而下降差超过0.2格，从较高的已确认空气格开始。后续甘蔗收割靠近植株并自上而下，保留全部根；第一根已完成开采后发生的新生长只在新扫描证明存在时另作新收割，未重放旧请求。

捆绑Python环境验证：test_stopped_air_pickup 5项、test_village_queue 28项、test_village_air_route 3项、test_local_air_path 22项，共58项通过。源码由后续规划器加载，保留原Minecraft主包、引擎与唯一持有的游戏控制器，不需要重启游戏。实机后续完成收割、工作台制作及全区安置核验。
