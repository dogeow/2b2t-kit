# 泥砖按实际工作量备料，缺料时使用成品继续施工

完整地图任务在仓库取得 52 个小麦后仍要求 64 个，重复补料而没有制泥。泥与泥砖的叶流水线最多生成四格新泥，依赖量却按 64 个计算，导致已有材料无法产生任何成品。

Kit 现在将黏土化泥与泥砖的依赖增量对齐为四个。完整目标不变，达到四格原泥工作预算时仍返回未完成回执；不能把一小批成品当成完整材料目标。

流水线两次没有进展时，若本次账本明确无自有在制格、未确认动作或装水瓶，并且当前实际背包有可用于图面的成品，施工调度器会先使用这些成品。未知回执、仅有保留数量或仍有在制资源时保持原停止边界。

179 项泥流水线、材料调度、平面地图及组合派发回归通过。新增覆盖四个小麦对大目标的真实部分产出，以及安全转建造、只有保留材料和在制资源三个边界。安装与组合实机效果继续核对，完整地图画及地图像素验收尚未完成。
