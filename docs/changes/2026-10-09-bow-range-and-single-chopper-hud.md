# 升空后的弓箭范围与单一砍树状态

主包 2026.10.9.1，Chopper 1.9.54，引擎 1.7.87，API 3。

实机在 `(760892.498,78.593,797988.453)` 悬停，已进入战斗的僵尸位于 Y=64，距离约14.6格。旧规则按敌人类型将普通僵尸限定在10格内，因此防护升空后取消了攻击资格，30秒没有确认伤害后保持停挖。玩家仍持弓，看起来像一直瞄准但没有放箭。

新增规则仅对已经进入战斗会话、实际存活、当前可见，并且背包有可用弓与箭的普通敌人采用40格弓箭范围。初次威胁触发、被动生物、玩家、遮挡、死亡确认与攻击进展计时没有放宽。射箭仍需宿主实时弹道、实际可见镜头朝向和完整蓄力确认。重新取得射击位时，即便敌人是僵尸，只要会使用弓也必须确认实际弹道。

HUD按用户要求只保留上方WorkHud任务条。`ChopperKeys.overlay`不再写入Minecraft下方动作栏，砍树状态与计数仍由原有状态字段进入上方任务条。

1856项Java测试通过，包含实际14.6格升空场景与未入战斗、无弓箭、不可见、已死亡、非敌对、超距的反例。构建和引擎结构检查成功。

当前实机仍运行旧主包与旧引擎。用户在手动砍树，暂未抢占控制、重启或热加载。新HUD需要主包重启生效；射箭引擎可在无冲突操作且满足健康条件时热加载。安装、运行版本和实际放箭结果须另行验证，不能将测试通过等同于实机生效。
