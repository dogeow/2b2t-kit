# 无箭时的远程威胁撤离

实机补光时，角色此前只有6支箭，僵尸防御期间六次原生库存观察各消耗1支。随后在约16.2格外遇到持弓骷髅，连续受伤后触发了低血量安全退出。原无箭分支只能原地防御；普通安全升空触发半径12格，没有覆盖这次距离。

引擎1.7.88让当前已交战、仍实际存在的远程敌人在40格内且没有可用弓箭时，触发已有安全升空。此分支使用固定32格目标，普通分支仍为12格；目标保持锁定，避免每帧不断增加高度。升空仍必须通过完整身体通道、当前服务器区块、实体和远离威胁检查，不改变攻击许可，不清除未确认敌人。该撤离也优先于普通进食暂停。

1859项Java回归测试通过，零失败，主包及引擎构建和引擎包校验通过。新增测试覆盖此次16.2格距离、弓箭仍可用时不扩大普通规则、交战与当前实体约束、40格边界，以及固定升空目标。

本次只离线修复和构建，没有安装、热加载、重连或解除健康保护。实机仍安装引擎1.7.87；新版实机撤离效果尚未验证。恢复后仍需先补箭、核对实际防护装备和满血状态，不能把代码测试当作生存保障验收。
