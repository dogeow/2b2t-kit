# 输入漏斗定向隔空放置

27.7扩展已有单格Meteor隔空放置入口，仅增加原图漏斗。普通投影打印器在本塔上层输入漏斗西侧为空时没有生成提案；不能要求该处存在同层箱子，也不能把重复走位当作施工进展。

漏斗点击面取原图输出方向的反面。原生在发送前使用Minecraft实际BlockPlaceContext预测方块状态，包含enabled状态，只有位置和完整状态都等于原图时才允许一次普通Meteor BlockUtils.interact。原图绑定、实际空气、正常交互距离、真实射线、实体碰撞、主手材料、Flight、健康及PvE条件继续检查；不修改方块结果，不更改模块设置，不自动重发。

源码与无源码回退的实际安装包各2217项测试通过，完整内部类依赖闭包通过。实机首格[761382,67,793985]确认朝西：一次use、发送后的服务器方块更新、库存8→7及两次完整现场扫描一致，随后满血返回高位。原始凭证保存在work/diamond-equipment-20261025/roof-recovery/depot-3cffb6e89a7b。其余坐标和整塔验收仍需独立完成。
