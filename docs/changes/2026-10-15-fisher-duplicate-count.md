# 自动钓鱼重复计数

`AutoFisher.castOrCatch` 原先在调用 `useRod` 后无条件增加计数。`useRod` 在冷却期间会直接返回；服务器还未移除旧鱼钩时，旧鱼钩可被连续处理。钩住实体的分支也会错误增加鱼获数。

修复将收竿状态绑定到鱼钩 UUID：同一鱼钩只接受一次收竿，冷却结束后仍等待服务器移除旧钩。只有当前仍在咬钩、未钩住实体且用竿交互被接受时计一次；冷却、拒绝、抛竿、空收及钩住实体均不增加计数。开始新一轮钓鱼重置计数和旧钩记录。

回归覆盖延迟移除同一鱼钩、冷却期间连续处理、交互拒绝、钩住实体、空收、不同鱼钩和新会话重置。

此修改属于宿主 `fisher/`，不能通过运行时引擎热更新。构建通过不代表正在运行的旧宿主已修复；需下次完整启动加载新版后实机核对。当前仍沿用“已咬钩收竿次数”的计数口径，没有新增服务端掉落/背包确认协议。
