# 末影人不再使用弓箭

森林第50区的真实日志显示，独立防护对同一末影人反复射箭，目标生命长时间保持34；站位被防护接管后补光暂停。用户确认弓箭无法用于这段末影人反击。

引擎1.7.89对已交战末影人使用独立分支：只有当前真实实体、仍处于激怒状态、视线可见、实际实体碰撞箱在正常交互范围内、耐久足够的剑可用时，才按原版攻击冷却用剑反击。远处举盾等待，不再拉弓、不为射箭寻路追赶。其它敌人仍使用原有优先级和防御路线。

已观察到末影人恢复中立、没有当前或近期攻击证据时停止给予攻击资格；持续20拍的当前观察可以解除该敌态。日志记作 `disengage-observed-calm`、`confirmed_deaths=0`，不会计为击杀。失踪、卸载、重新激怒、近期受击或其它仍未解决敌人，都不能被这一解除路径当作完成。

验证：1865项Java测试通过；包含20拍中立证据、缺失/重怒重置、保留其它敌人，以及末影人分支在选弓前执行、合法剑击范围和禁止追赶的实际接线回归。未进行新引擎实机杀敌验证；当前主包9.2不需要更换，需热加载外部引擎。

当前原游戏操作已因12:21:24的“手动移动接管”结束。第49区实扫0暗点；第50区核实4支火把，最后实扫2暗点，旧施工暂停和回执保留。部署不能自动覆盖用户手动接管。

补光的显式原生防护选项已支持9.2/1.7.89配对，9.1/1.7.89等未经验证的配对仍拒绝；265项补光测试通过。
