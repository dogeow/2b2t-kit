# 在原矿区内控制单次采集岩石工作量

原102块凝灰岩矿区6×18×6最多648块岩石，原生时间上限600秒。目标库存只计凝灰岩，而清理/移动还需普通岩石，不能按成品数缩小期限。新增世界可配置 `rock_collect_max_remaining`，候选盒仍位于原授权矿区并保留原入口，只选实际剩余岩石不超过该限制的小盒，采集目标仍被当前实际可取数量和真实库存限定。未设置保持原648；当前准备使用180，匹配已观察每块约数秒与600秒上限，不改变全图、原矿区或所需材料。每次完成仍由原生回执和真实增量确认。

108项自然发现与采集回归通过，包括原648的大源保留、180工作量选原源内支持子盒、入口不能丢失、期限上限及原有控制/战斗失败不重放。当前代码已在线安装，原矿区内180工作量设置已登记，较小采集盒尚待矿层工序实机验证。上一工序目前已正常结束高空防护，原更深入口因容量停下的未知记录保留；继续前需当前预测核验和存放副产物。
