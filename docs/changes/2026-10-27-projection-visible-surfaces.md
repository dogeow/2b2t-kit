# 施工站位可见表面与补丁依赖闭包

原施工规划只检查方块中心射线。实地玻璃格上方有石头时，中心被挡，但正常放置所需的底面或边缘仍可见，因此会出现开采完成后无法选出打印站位。

ProjectionReachability 先检查中心和表面中心，再检查严格位于目标格内部的表面采样点。原有中心距离上限、每条射线距离、身体碰撞、流体/危险方块、实际投影打印交互和服务器确认保持有效；可见点只是规划候选，不能作为放置完成证据。最终场景仍逐属性精确核验。

完整源码2203项Java检查通过。首个27.2限定包的隔离类路径错误地保留了源码目录，掩盖漏打包的编译器枚举switch类 ProjectionReachability$1；实机出现NoClassDefFoundError并退出。修正版27.3补齐完整助手类族，去掉源码类目录和项目构建JAR回退，并检查没有其它类路径提供同名助手。坏包在新隔离环境中复现4项失败，修正版59项候选检查全部通过。

tools/check_jar_class_closure.py 可独立核对指定修复类族引用的项目内部类是否实际位于候选JAR；包括生成类与方法描述符引用。它不替代JVM字节码验证或实机验收。检查器4项回归通过。
