# 剩余暗点使用已亮邻地支持点

第54区实际剩14暗点，僵尸防御把角色升高后，旧低站位导航又下降，触发反复防御。通过所属任务原生pause停止该导航，再实扫上升身体通道，实际到达Y130、20生命/20饱食，原日志和未确认导航保持原样，没有击杀记账或放置重放。

补光候选新增两个显式选项，默认行为不变：`target_bounds`只统计指定目标里的暗点，完整更大扫描仍用于屋顶/地表判断和路线证据；`hostile_clearance`让放置站位远离已实际扫描到的敌对生物，并允许选用附近已亮的自然支持方块照亮这些暗点。选址距离不是免战保证，路径和放置仍需原生碰撞、守卫、视线、触及及两帧库存/实物验证。

268项补光测试通过，新增用已亮远侧支点、目标外暗点不替代目标、无效参数拒绝的回归。当前实机开始从北侧接近，角色仍满血；最终原54边界零暗点尚未证明。
