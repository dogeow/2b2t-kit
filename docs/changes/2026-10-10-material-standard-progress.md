# 顶部材料任务标准进度

完整地图外部施工入口没有发布 `job-progress.json`，因此原生 HUD 只能显示零散动作。现在材料后端在既有观察点发布当前主工序、实际背包成品数量和绝对目标，例如 `制作 泥砖 · 30/128 · 地图 8966/16512`。嵌套取小麦、取土、装瓶等不会把主制作目标替换成一个小批次。地图数字来自最近已验证的完整施工状态，不把新做的材料当作已放置方块。

物品中文名称读取当前游戏已下载的资产，缺失时显示真实物品 ID。发布器仅写显示文件，不取得游戏控制、不发游戏动作、不改施工或配方账本。当前世界、服务器、维度、任务和材料租约必须一致；手动输入、暂停、结束、过期或未知数据立即隐藏。背包数量允许减少，不累计配方计划或仓库缓存。以仓库成品总量为目标的流水线不会拿背包数量冒充完成数。

HUD 的另一处问题是避让 Jade 时只判断水平重合。当前 Jade 设置位于屏幕底部，原逻辑把顶部任务条推到底部以下并隐藏。现在只避让与顶部面板垂直重合的提示框，保留顶部六像素间距，不更改用户 Jade 设置、不恢复底部绿色重复 HUD。

提供同一只读发布器的命令行入口，供已经运行、尚未载入新后端的任务临时发布进度。新任务自动使用后端内建发布。主包版本 `2026.10.10.3`；AutomationBridge.class 与 `.2` 字节和 SHA256 一致，保留精确补种拒绝恢复契约。

验证：247 项材料进度、后端、状态机、泥流水线回归通过；141 项主包契约、进度、后端和发布打包检查通过。Java 全量 1901 项检查、主包构建与引擎校验通过。构建已包含此前准备的地图工位16格批次改进。当前游戏的可见结果与安装记录另存实机证据，不能用这些测试冒充实机或完整地图验收。
