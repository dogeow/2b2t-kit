# 砂土配方沿用已验证批量合成

实机制泥首批砂土按四次单轮背包配方合成 16 个，共消耗 8 泥土、8 沙砾。配方尚未进入既有无容器余料的批量白名单，导致重复准备四套输入和确认输出。

`stack_recipe.supported` 只对白名单中确切砂土配方启用已有批量执行器：输出四个、泥土与沙砾各两格、四个不同合法配方格。现成容量规划、原生普通点击、后续双帧和输入输出守恒保持原实现。输入相同的 8 泥土与 8 沙砾可组成四轮、一次输出点击取得 16 砂土；大任务范围不改变。

125 项配方、制造、库存和泥流水线回归通过；批量规划消耗相同物资，非法配方拒绝。新批量尚未专门实机验收，不报告速度倍数。当前任务首次合并空瓶已实机完成且无箱子往返，原健康等待防护超过两分钟保持在线；首次四个夯实泥土已真实制成。后续泥砖点击因物品界面变化暂停，原记录保留，当前光标和合成格为空且夯实泥土仍四个，以现物独立继续。
