# 日常种田只维护既有耕地

AutoPlanter 的日常扫描不再创建锄地任务，也不会选择或使用锄头。旧 `planterTill` / `planterStack` 配置保留兼容，但不再授权日常开田、叠种甘蔗或在普通地面扩种。界面改为明确显示“仅维护已有耕地”和“不向田外扩种”。

旧 AutoPlanter 没有持久田块登记。本次启动会在原有扫描范围内，仅把当时真实为 `minecraft:farmland` 的土层坐标记录为会话白名单。日常扫描、播种和收成仍要确认该位置当前是耕地；启动后新出现的耕地也不会扩入本次名单。普通草地、泥土、小路、灵魂沙及装饰不属于维护目标。

播种只接受耕地上方真实空气，不因 `canSurvive` 或 `canBeReplaced` 就覆盖植物或装饰。选取种子、瞄准和原有混种/灌溉检查完成后，临交互再次读取土层和种植格；任何一格改变都会取消该次交互。成熟作物也必须仍在会话原耕地上，且真正破坏前再次核验，避免把边界作物或已被玩家改动的地块纳入。

显式的新开田仍由独立、有中心/半径授权的 `farm prepare` / `farm plant` 流程负责。本修复不修改这些 Python 流程、不回滚世界，也不重建已有 5×5 小麦田。自动日常服务的 Python farmland-only 路径由对应模块单独处理。

新增回归使用真实原版 `BlockState` 的可变田地场景：5×5 耕地与外圈草土、会话外耕地、扫描后土层改变、临交互出现成熟作物或装饰、成熟边界作物和特殊植株。动作回调是实际生产交互门槛，断言被拒绝时没有播种调用；另核验运行类确实接入边界且不会选择锄地任务。

本次不部署、不控制游戏、不修改版本或提交 Git。由主线程统一完成版本、构建与安装验收。
