# 普通停靠漂移保留所属施工会话

21版实测在三次恢复Flight后仍偏移时，异常可能进入 `AutomationBridge.tick` 的通用异常处理：它把普通运动终态当作世界/人物变化撤销控制版本，原失败原因也被替换。这会阻止后续只读核验实际站位，导致不必要的收尾和重连。

22版为耗尽三次恢复的情况使用专门 `RestoredFlightDrift` 异常，仅在对应导航观察分支捕获，以 `stopped` 正常结束原航点并释放其按键/临时飞行设置。不会报告到达成功，不增加容差，不重试，也不改变健康、世界、人工接管及通用异常的中止路径。

后续任务若要使用附近站位，仍须独立三帧只读证明，再从实际位置通过正常原生射程、视线和目标校验。本改动没有确定或修复物理位移的来源。

229项相关产物测试通过，包含专门异常类别、已耗尽恢复次数、正常停止不撤销会话及通用异常仍保留中止路径的回归。宿主变化需要完整重启；实机接续另记施工凭证。
