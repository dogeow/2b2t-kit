# 制泥工作槽优先合并空瓶

用户一次拿入沙砾 190 和小麦 101 后，背包只剩两个空槽，旧制泥准备只会检查多余种子与泥土可存放量，连续两次 WAIT_WORKSPACE。当前三个普通空瓶分别占三槽，本地合并即可腾出槽，不必往返箱子。

`prepare_mud_inventory` 优先调用 `material_stack_consolidation.run_inventory` 合并普通空瓶，再保留既有成品堆叠与多余原料存放分支。复用 `InventorySession` 和 `move_amount`；只能操作普通无组件堆叠、空光标和空合成格，每次先保存 pending，并核对两个后续当前帧、空光标、源槽清空、目标增加及全背包物品总量不变。未知点击和已有日志不重放。

209 项相关回归通过，包括实际转移原语驱动的四次普通点击合并三个空瓶，腾出两个槽而所有物品数量不变。后续由实机工作槽整理及制泥验收；不把合并当作新物品或地图施工进度。
