# 从已静止的邻近位置继续施工

21版诊断捕获了低层停靠失败：恢复Flight后按键及游戏采样输入全零、无伤害或碰撞，数拍后实际位置偏移约0.57格。目前未查明位移来源，不能宣称修复了导航，也不能扩大原生精确到达容差。

新 `material_jobs.stationary_approach.observe_nearby` 保留原生 `stopped` 和原请求身份。它仅处理明确的恢复Flight漂移终态，在同一世界、控制版本和唯一租约内，核验满血满氧、保护开启、无人工输入、无未确认操作、无待退休扫描、当前位置与目标水平距离不超过0.75格且垂直不超过0.15格，再以三帧新扫描证明角色静止和身体实际净空。

输出始终为 `exact_waypoint_confirmed=false`，另记录实际施工站位。此入口不执行或重试导航、挖掘、放置、攻击、桶操作；后续动作仍从实际位置重新经过原生射程、视线、目标和保护校验。未知操作、人工/健康变化、仍在移动、非指定失败原因、占用或液体空间均拒绝。

这是可热更新的只读判断，不是主插件到达规则修改。相关20项Python测试通过；实机采用情况需按独立证明记录。
