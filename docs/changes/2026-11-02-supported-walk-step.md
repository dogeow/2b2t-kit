# 普通行走禁止隐式关闭飞行下落

防护抬升后，旧脚本仍向原地面坐标发送普通行走并关闭飞行，造成非预期下落。主包 2026.11.02.18 在关闭飞行前要求目标有已加载、可碰撞的落脚面，且高度差不超过 1.1 格。普通行走与分段路径也记录当前行程的起始高度；实际高度离开起终点范围超过 1.5 格时保留飞行制动并终止该旧行程。

显式换气水下降和带制动高度的受控自由落体仍走原有专用验证；人工接管与安全锁继续优先。较长的上下楼路线需要已观察的分段路径，不能使用普通行走隐式下降。

新增 8 项回归覆盖半砖台阶、普通跳跃、保护抬升后的旧坐标、跌离路径和非有限数；连同现有相关检查共 52 项通过。经验总点数与进度字段继续保留。安装完成和实机通过应分别记录，离线构建不代表已完成游戏验证。
