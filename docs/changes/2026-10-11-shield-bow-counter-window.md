# 骷髅盾弓反击窗口

实机记录显示骷髅交战时副手盾确实发生磨损、实际举盾状态反复出现，但经常回到举盾等待。角色在这段交战中掉到18血以下，原材料任务暂停；旧煤矿材料回执保持原样，当前背包确认有12煤。

旧策略要求连续实际举盾8 tick，并只允许20 tick满蓄力射箭。现在观察到真实盾牌磨损且没有来箭、受伤时直接打开反击窗口；没有这种观察时仍保留原等待和真实举盾要求。启用新宿主能力的盾牌反击允许16 tick放箭，轨迹用实际蓄力计算；迟于16 tick释放也根据实际蓄力重算。来箭仍取消反击，近身与末影人规则保持原有约束。

BorerHost新增可选默认接口，旧宿主默认不启用短蓄力，保持20 tick协议；API仍为3。普通弓箭及其他目标也保持20 tick。宿主实现复用既有BowAim/BowTrajectory，不在引擎复制宿主弹道逻辑。

1915项Java测试全部通过，主包、引擎包及依赖校验成功，包括盾牌磨损即刻反击、短蓄力目标与视线要求、真实放箭钩子和对应轨迹速度。已安装并实机加载主包2026.10.11.6、引擎1.7.97。原版本备份在 `work/live-20261004/shield-bow-review-161/install`。
