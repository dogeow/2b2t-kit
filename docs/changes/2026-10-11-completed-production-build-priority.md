# 一批成品完成后优先推进图面

平面地图施工返回的大批缺料数量会进入材料调度器的 `prerequisites`。该分支绕过普通投影批次中的 `has_ready_projection_output` 判断，导致泥砖已从实际 2 块加工至 18 块后，仍继续以 34 块为新背包目标取料，而没有先推进图面。

现有流水线返回 `done` 后，调度器先独立检查真实背包达到本次绝对目标。只有当前没有活跃加工、后端未拒绝安全离开，且已有投影入口证明成品可放时，才将实际新增成品登记到既有 `pending_ready_build`。下一步复用既有施工入口，后续缺料由真实施工回执重新计算。全图目标和物资总量不变，未完成、待核对或不能安全离开的流水线仍保持原来的处理方式。

127 项相关 Python 检查通过，新增覆盖大批施工缺料不会压住已完成小批成品、持有在制品不得转施工，以及没有可放成品时保持原缺料目标。安装和新实机运行证据记录在当前施工目录，源码检查不代表实机验收。
