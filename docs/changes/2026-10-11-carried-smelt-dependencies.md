# 已有熔炼原料与新加工依赖

地图施工回执可能先要求一批成品，例如深板岩背包总量 70。后续加工发现缺煤时，原调度器把新燃料依赖追加到成品要求之后，仍然优先尝试同一个没有燃料的加工，两次无进展后停止。现在新回执要求的依赖优先处理，旧的成品要求保留到依赖满足后再继续。待确认在制品的停止规则不变。

新的平面地图熔炼批次规划会优先使用已经实际携带、无附加元数据的原料，而不是立即取更多原料来凑满默认 128 件。原料达到登记的一整组运输量（或目标的准确尾量）且在登记炉组容量内，才生成规划。例如实际携带 68 块粗深板岩、2 块深板岩，可先提出背包成品 70 的批次。燃料仍由原加工适配器检查、取料仍由已有仓库流程确认，规划不获得库存或施工信用。
