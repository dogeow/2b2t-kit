# agent-wow 的执行架构与 Kit 提速

研究版本：`agent-wow/agent-wow` commit `5ef49162c396aa230807820c4d1d11896fb7467c`。本记录依据源码比较执行结构；没有两个游戏的同条件速度测试，因此不提供倍数结论。

## 已确认的设计

`char play` 建立持续的游戏连接，并提供本地 JSON-RPC。模块随游戏会话启动，使用持久 gRPC 连接；高频工作可以在模块内完成。核心仓库的内置玩法方法只有 `session.logout`，移动和战斗等能力由模块实现，不能把该框架本身当作已包含全部玩法的机器人。

- [会话源码](https://github.com/agent-wow/agent-wow/blob/5ef49162c396aa230807820c4d1d11896fb7467c/pkg/world/session.go)：一个读循环、一个拥有协议状态与发包权的循环，其他调用者读取快照或提交命令。
- [事件派发](https://github.com/agent-wow/agent-wow/blob/5ef49162c396aa230807820c4d1d11896fb7467c/pkg/modules/runtime/manager_packets.go)：服务器包进入订阅模块的有界队列，派发不等待模块处理；每个模块顺序消费，溢出或回调失败结束会话，避免静默丢失事件。
- [模块调用](https://github.com/agent-wow/agent-wow/blob/5ef49162c396aa230807820c4d1d11896fb7467c/pkg/modules/runtime/manager_invocation.go)：模块依赖调用使用类型化消息与已有连接，调用耗时被记录。
- [会话接口](https://github.com/agent-wow/agent-wow/blob/5ef49162c396aa230807820c4d1d11896fb7467c/api/module/v1/session.proto)：共享单调时钟；发送成功仅证明写入传输层，未证明服务器接受，取消后未知的发送不能自动重试。

持久连接和事件派发有利于减少调度等待，这是源码结构上的推断。WoW 的协议客户端也不承担 Minecraft 实机客户端的方块碰撞、区块加载与建造状态检查，不能直接移植其发包行为。
