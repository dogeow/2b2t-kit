# 连续低空补光与防御升空修复

之前每支火把都先升到区域巡航高度，再平飞、下降并返回高空；多拐点和脚部高度微调造成额外停顿。连续批次现在在已完整读取的附近空间规划低空路线，合并直线并仅在完整体积无障碍时减少转弯。中间路径使用 0.195 格脚部余量，动物占用的站位和路径会被排除。跨区和安全收尾仍使用核实后的高空。

每段移动仍由原生 `air_only` 验证实体和方块碰撞，火把仍需后续两帧真实方块与精确库存变化。已有未知放置不会重放。零暗点完整扫描可以直接用作最终复核，避免重复同一扫描。

`native_guard_only` 是显式开启的已验证主包/引擎组合选项；忙状态缺失或非布尔值仍阻塞。未开启时维持原有防御检查。原生防御不会被关闭。

宿主 2026.10.9.2 修正 `GuardEscapePolicy.currentLease`：导航接管停止旧控制后已将请求和所有者同步到当前 revision，执行期验证也必须检查当前值。之前误要求 current-1，导致合法的垂直防御升空停住。原生水下返气请求也使用当前值，入口旧 revision 拒绝规则不变。引擎保持 1.7.88。

验证：1860 项 Java 测试、260 项补光 Python 测试通过。9.2 主包已正常重启并实际加载，旧导航及未确认敌人记录保留，没有计作击杀或施工完成。第一版实机连续路径在 Y76.1～79.1，三个间隔为 20.74、36.78、18.48 秒；这些不是最终优化版提速百分比。新世界首个连续样本为 14.499 秒，含 2 次导航（合计 5.565 秒）与扫描（4.609 秒），路线为 Y80.195→79.195，无中间升空。第 48 区实际放好 2 支，暗点 51→6。后续横移发生偏移，被原生碰撞检查以 waiting 停止；当前起点连接与缩短路线增加横向余量，未知结果没有重放。此单样本不能证明全岛平均提速。

原始 150 区台账未改，森林第 46 区仍有 1 个暗点、第 48 区当前扫描 51 个；全岛补光及地图画尚未完成。

## 较高的近距站位

健康退出恢复后，新增显式 `station_height` 选项（默认仍为1.1，允许1.1～3.3）。当前森林批次使用3.3：相对于目标支持方块升高近距站位，仍需完整的视线、正常触及距离、净空和原生碰撞检查；低树冠没有合法高站位时不会强行穿过。邻坡可能比目标支持方块更高，因此该参数不能证明对所有地形的离地高度或免受攻击。

263 项补光测试通过。当前 a724 世界第49区已核实新增2支火把，暗点39→2，尚未完成最终复扫；这是部分实机证据。
