# 整个制泥批次集中合成候选

当前实机已验证 16 格制泥的原料准备与原格单次放置、装水、转泥、挖掘和拾取，但每获得四个泥都会合成一次夯实泥土和泥砖。既有背包制造器已经支持这两种确切配方的多轮执行，额外往返主要来自重复准备配方格和确认输出。

`flat_map.bulk_mud_recipe_batches=true` 明确启用、且原 16 格携带容量已核对时，优先一次取得本次需要的泥，再调用原制造器批量合成。已有夯实泥土仍从新泥需求中扣除；保留同一 16 格物理工作上限、256 次操作上限、每格服务端确认、库存守恒及未知动作不重放。默认及无法证明容量的请求继续采用四格合成。

306 项相关 Python 回归通过：现物原料 16 泥和 16 小麦可用一次夯实泥土配方及一次泥砖配方得到 16 个新泥砖；真实已有四个夯实泥土仍保留，未知挖掘不重复。候选尚未安装或实机验收，与图面直接平飞候选一并等待当前程序自然终止后再验证。不为部署主动重启正在生产的程序。
