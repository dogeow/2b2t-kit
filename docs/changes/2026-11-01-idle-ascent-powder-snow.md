# 待机热伤升空保护细雪

待机热伤恢复原先只用实体碰撞和岩浆判断上升净空。细雪对普通实体可以没有阻挡碰撞，但26.2原生服务端会销毁着火玩家接触的细雪；因此碰撞检查通过仍可能破坏已经铺好的细雪。

引擎1.8.44在原有已加载服务器区块、碰撞和岩浆检查之外排除细雪体积。候选上升高度仍从3格逐步降至0.5格，选择完整身体范围不会接触细雪的最高一步。普通雪层和从当前火焰中升出的原行为保留。没有垂直净空时仍交还原有保护流程；本次没有新增侧向寻路。

验证：

- 从当前安装引擎隔离制作候选Jar，90项相关检查全部通过，包括实际机型高度下的细雪/顶棚场景、没有最小可行上升步长、普通雪与火焰行为，以及实际Jar接线检查。
- 候选只改变待机上升材料判断与引擎/导航版本标记；当前安装的BorerThreats字节保持一致，没有混入工作树另一项伤害分类改动。
- 完整离线Gradle检查在编译前因缺少Fabric Loom1.17-SNAPSHOT插件缓存失败；不能将隔离候选测试称作完整Gradle构建通过。
- 已通过原生热更新入口安装，游戏确认引擎及导航均为1.8.44，世界未切换，背包数量保持一致。没有故意让玩家着火穿过细雪进行破坏性复现。

本修改不把细雪缺失的现场原因认定为已证明，也不代替补回缺失方块和整塔生产验收。
