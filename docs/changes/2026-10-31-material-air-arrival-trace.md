# 材料航点恢复飞行诊断

低层检修廊曾在恢复用户 Flight 设置后偏移约 0.6 格，重新接近三次仍失败；高空相同方向路线却通过。不能凭这些结果断定是斜向移动、输入冲突或服务端纠正。

宿主 2026.10.31.21 在每个材料航点内保留最多 128 条只读记录：按键位图、游戏实际采样输入和移动向量、位置和速度、朝向、碰撞/受伤状态，以及当前 Meteor Flight 模式、速度和反踢计时。位图从低到高为前、后、左、右、跳跃、潜行、疾跑。

常规运行快照仅增加 `material_air_navigation.trace_protocol=1`。导航结束时的 `material_air_navigation.trace` 才导出记录，避免每拍输出整段历史。阶段含 `input_head`、`observed`、`before_restore`、`after_restore` 和 `reacquire`。诊断不写入玩家状态、按键或 Meteor 设置，不改变到达条件，不重放未知操作。

候选包仅从已安装20版本替换上述诊断相关类及版本信息，其他未提交改动不包含。宿主变更需完整重启。227项相关产物测试通过；上线和低层复现须另行记录，测试通过不代表偏移已修复。
