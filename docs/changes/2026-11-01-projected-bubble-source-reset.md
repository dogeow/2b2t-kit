# Reset accidental bubble sources in projected flowing-water cells

`projected_bubble_reset.reset_group` adds a reusable material-worker operation for connected groups of accidental downward bubble columns. It accepts only original ordinary flowing-water cells over unchanged original magma blocks. Original sources, omitted adjacent bubble cells, changed floors, duplicate coordinates and disconnected groups are rejected.

The worker temporarily replaces every group cell with dirt through normal block interaction, verifies the placed block and inventory decrement, then removes each known plug with the existing pinned wet-terrain mining interface. Each removal requires the native block update and matching sequence acknowledgement. Three fresh group observations must show ordinary flow or air with no surviving source before the group is complete. Bucket inputs and additional native mining exemptions are unnecessary. Every input is journaled first; unresolved actions remain pending and are never retried. A same-world interrupted plug stage may resume only when its original journal has no pending action or started mining. Fresh state must match every confirmed dirt plug; those placements are skipped, not replayed.

The caller retains the single material lease, plans collision-checked side approaches, and restores its service opening. Group completion does not prove the entire water network, redstone operation or farm production. No host, engine or Mixin replacement is required: this module is hot-installable with the existing worker interfaces.

Validation: twelve targeted tests cover original-source protection, original-floor preservation, connected complete groups, coordinate validation, existing-flow preservation matching native mining acknowledgements and restricted plug-stage resume. The adjacent water-operation suites bring the targeted total to twenty-one tests. The underlying fill-and-remove sequence was verified live before extraction; installation and subsequent worker execution are tracked separately in the construction journal.

Live water-level changes exposed a preflight race: select the shovel before reading neighbor pins. The exact before-task pinned-neighbor refusal retains the known plug with a separate no-input record; running mining metadata and all other errors remain unresolved.
