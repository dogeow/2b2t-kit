# 封闭落摔室的防护工位

原防护把封闭室内未蓄爆、无法看到玩家的低血量苦力怕按开放环境处理，反复带离经验拾取工位。

引擎 1.8.46 对已登记的当前交战目标重新检查真实世界碰撞：连续干燥地面、最多 3×3 的内部空间、从地面到实体上方的完整实方块围墙、内部无台阶或液体，玩家位于室外。普通跳跃、步高、重力和当前上升速度均受限制。只处理列出的普通地面怪物；未观察到的目标、受击、投射物、蓄爆、点燃、充能、异常移动能力等情况不获得此判定。

封闭井内正在下落的目标需要验证整个下落通道。远处未交战的怪物不混入当前交战目标的封闭证明。判断每次重新读取已加载服务器区块并拒绝待确认方块预测；不清除目标记录，不计作击杀，不改低血量或安全离线锁。

构建采用已安装引擎作为基底，仅替换相关类和版本。103 项相关检查通过；其中包含缺墙、缺地面、内部台阶、过小实体、异常移动和下落通道缺口回归。产物尚须在本次安全事件恢复后安装并验证实际工位。
