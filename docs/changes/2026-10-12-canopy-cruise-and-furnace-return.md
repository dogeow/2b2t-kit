# 树冠下巡航与装炉恢复

普通巡航在调整高度时停止水平前进。如果头顶被树叶挡住且清顶关闭，原先会持续按上升；精确抵达的高度分支还会提前返回，错过后面的清顶/避障处理。

新增最多 6 格范围内的水平出口搜索：先沿当前高度离开树冠，再继续原高度与目标。每一步检查玩家完整碰撞箱、真实服务器区块、液体和实际前进方向；出口还必须有完整上升净空。路线不挖树，不修改原巡航坐标。临时使用已有 Meteor Flight 会话控制精细速度，完成、停止或世界变化后按所有权恢复；保留用户后续手动设置。材料的 air-only 航点仍维持原有核验路线。

Java 1923 项回归及宿主/引擎/可选 Xaero 打包检查通过，覆盖树冠下平移、绕开树干、阻断/未知出口及疾跑时精细速度。宿主版本 2026.10.12.2，运行引擎仍为 1.7.98。用户明确要求“**不着急装，等下次**”，因此本轮不安装该主包、不重启游戏；实机树冠脱困与 Xaero 右键菜单仍待后续安装后验证。
