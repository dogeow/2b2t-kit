# 固定树采木超时后的实际目标核验

实机固定树已确认清空树冠，16根目标原木全部进背包，临时平台泥土也全部回收；原生砍树仍追逐低处的树苗和木棍，最终达到请求时间上限。原回执为STOPPED，不能因为库存够数把它改写为DONE。

`chop_goal_receipt.allow_deadline_goal_audit`只允许对这种明确停止作独立核验：原请求、当前世界、任务、监督者和控制版本必须匹配；未知或仍在飞行中的请求拒绝；当前砍树必须停止、整树计数为1、平台为0，目标原木增量和泥土数量必须精确匹配，角色健康且没有真人接管。回执发布时仍显示chopping=true的竞态，必须等待当前状态实际停止。

函数通过仅表示可以继续读实际树冠，不等于整树施工完成。调用流程还必须两次观察精确库存、扫描确认原木全部清空，再按真实根部状态恢复原树位。旧STOPPED回执和未回收物品记录保留，禁止重放旧砍树、伪造原生完成或省略实物核验。

8项离线回归通过。实机16根增量、32根现货、4泥土归还、空树冠、原树位补种和高空KEEP已分别取得证据。此模块在本地工作流程中使用，尚未改动宿主砍树器，也没有为这项改动重启游戏。
