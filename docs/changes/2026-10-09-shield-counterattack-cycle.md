# 真正举盾后再反击弓手

实机骷髅反击日志中副手盾保持满耐久336，using_shield=false，玩家仍受到箭伤。旧raiseShield只按使用键，主手弓优先进入使用动作，因此没有真正启用副手盾。

引擎1.7.90改用正常Minecraft交互接口显式使用正确手中的盾。对独立防护中的骷髅、流浪者、沼骸和掠夺者采用盾优先循环：真实blocking状态持续足够时间，盾耐久损耗或受控等待允许一次反击窗口；新来箭预测、新受伤、攻击窗口过期都返回防御。实际剑击或弓释放后重新防御。冷却期间也举盾。弓释放回调再检查来箭，只取消旧释放，下一正常tick举盾，避免把旧回调应用到新的盾使用动作。

盾状态机只规划反击机会，计时不当作箭被挡的证明。原有目标交战证据、苦力怕优先级、撤离、可见弹道、射线与停止/手动接管继续保留。末影人仍不使用弓箭。日志记录实际using_shield、isBlocking、盾损耗与健康，不能仅用HUD字样验收。

1871项Java测试、268项补光测试通过。外部引擎已在当前a724连接实际热加载为1.7.90，主包9.2保持，未退出游戏。加载证明：`managed-load190-a724-001/actual-loaded-engine190.json`。当前没有新循环的实机挡箭证据，等待后续真实遭遇；原59区受伤下降及恢复高空记录保持原样。

弓现物161/384，附魔无限I、冲击I；备用普通弓249/384，经验34级。当前26.1.2游戏JAR的exclusive_set/bow明确包含infinity和mending，现弓不能通过经验修补恢复。用户授权修补后计划在现有铁砧合并备用普通弓，核实原附魔、结果耐久、实际费用、两帧槽位和背包守恒后才领取。
