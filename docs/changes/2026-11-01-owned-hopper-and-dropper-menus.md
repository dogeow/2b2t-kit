# 自有漏斗与投掷器菜单归属

现场材料任务正常打开漏斗后，主包将HopperMenu当成了外部人工界面，触发交还控制并停止了任务与保护。原归属名单支持箱子等界面，但缺少漏斗及投掷器共用的DispenserMenu。

本次只在原生interact等待开箱的分支加入这两种菜单，要求当前材料任务仍持有有效控制权且没有人工移动输入。原有人工接管、商人独立归属和未知界面规则保持；增加owned_added_container_menu_protocol=1供调用者在尝试新菜单前检查能力。

下一主包源码版本为2026.11.01.15，属于宿主修改，需要完整重启。当前实际安装仍为14，候选只有菜单归属修复，不应作为剩余主包功能已齐全的发布包使用。

验证：实际隔离候选编译成功，27项归属、界面暂停、加工菜单及控制权相关检查通过，包括真实AutomationBridge字节码接线与能力字段。扩展试跑中的两项未修改库存恢复测试在原安装包与候选上均因26.2独立测试环境组件尚未绑定而失败，原日志保留，没有修改这些测试来制造通过结果。完整Gradle离线校验在编译前因缺少Fabric Loom1.17-SNAPSHOT插件缓存而失败；不能据隔离测试声称完整构建或实机漏斗验收完成。
