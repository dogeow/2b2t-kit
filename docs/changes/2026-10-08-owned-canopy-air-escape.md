# 固定树台的侧向升空

固定树台只有少量落脚方块，长成的树冠可能挡住垂直升空路线。材料客户端新增 `owned_air_escape.escape_side(client, out)`：先观察最多八格的侧边空气通道，再由 Kit 原生空气导航侧飞、检查实际身体所在的完整竖列并升高。

调用发生在已有材料会话中，使用同一客户端、任务和看护。入口核对已知空闲回执、健康、手动输入和完整库存；每段飞行都有原生导航复核。结果写入独立输出目录，保存扫描、规划和实机高空到达证据。

当前入口适用于脚部处于整数高度的固定树台。调用方可在 `route_geometry_blocked` 且原请求已经确认结束时选择该入口。未知回执仍由原有 `RetainedUnknownMaterialClient` 保存。

完成扫描的回复可能早于状态文件清除待扫描字段。入口会在同一已知任务、世界和控制版本内观察最多六秒，等待状态发布；所有者变化或未知结果立即交还原有处理流程。

验证包括六项回归测试：身体扫掠范围以外的方块、单格树台下的树冠、完全封闭或有液体的通道、八格范围上限、已完成扫描的发布延迟、所有者变化及未知结果。

实机证据位于 `work/live-20261004/cherry-fixed-native-batch-host79-009/same-owner-canopy-recovery-001/`：使用原有任务，库存308块木板保持不变，侧飞后到达Y129.86，完整身体竖列净空64.86格。初次收尾在扫描状态发布检查处停下，恢复入口等待并核对同一任务后完成退出；该事实不改写原始停止记录。

此改动位于 Python 调用层，宿主与引擎版本保持当前安装值，无须重启 Minecraft。
