# 返图前凑齐有效成品数量

凝灰岩首个区域只有5块，原调度器把背包7块直接作为返图信号，铺完5格后再次远行。新增世界可配置 `minimum_projection_trip_stack=64`：返图前统计当前完整模型中可直接施工的缺口、排除旧未知格、只计普通主背包堆叠；同物品多个普通堆叠可合并计数。一般凑到64，最后少量缺口只需缺口+2预留，旧未设置规则仍按原3块门槛。
