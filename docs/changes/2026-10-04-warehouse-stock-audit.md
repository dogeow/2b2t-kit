# 岛上仓库只读库存核验

入口是 `decision-runtime/kit_cli.py materials stock`。它只读取明确传入的容器坐标，不取物、存物、放置或拆开潜影盒。只能在没有其他控制者的健康、高空、已验证加载柱和 PvE 保护状态启动；容器访问继续使用 Kit 的实际碰撞与可见面检查。门路线到 Y65 不证明 Y69/71/72 的木桶可达，缺少同层阁楼退出路线时在进入前等待，不拆屋顶。

```bash
cd /Users/sam/Code/DogeOW/minecraft-kit/2b2t-kit/decision-runtime
'/Users/sam/Library/Application Support/MinecraftDecisions/venv/bin/python' -B kit_cli.py materials stock \

```

重复 `--depot X Y Z` 可指定同一次核验的 1..64 个坐标。输出目录必须为新目录；已有证据不覆盖、不自动重放。上例是供唯一实机操作者使用的命令，本文更新过程中没有执行游戏核验。

### 进入前证明退出

侧面机器与木桶站位采用至多两格的四侧候选。机器须先证明原高空位置到候选上方的完整身体走廊，以及候选站位到上方的开放升降柱；再保存有限的原路返回点。房屋在原登记门路线进入后，只使用同层候选站位，并先证明可返回原入口结束点的身体走廊。全部导航复用实际起点、至多 31 格的原生 `air_only` 航段，逐段重新扫描和确认到达。原生交互仍核对精确方块、可见面和距离。没有可证明的返回路线时不下降进入。

正常读取和已知非修改操作失败都会先关闭本任务的空光标菜单，沿原返回点退出；房屋随后走原登记 `workbench_exit`，再从实际室外开放柱停车。精确请求 ID、世界、版本和同属空闲材料 lease 确认的扫描/移动/接近/选物/关闭菜单 terminal，可执行安全退出。原生交互仅三个明确在 `useItemOn` 前抛出的错误（目标方块改变、手持物改变、目标不可见或超距）允许此清理；其它交互错误仍保留。未知、外来、过期回执及仍忙碌操作不追加退出、停车或新请求。出口在返回前改变则停止，不穿屋顶。
