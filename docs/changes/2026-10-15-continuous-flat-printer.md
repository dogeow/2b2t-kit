# 平面地图画边走边打印

此前 `ProjectionBuildJob` 在每段走位中暂停 Litematica Printer，并在站位结束时销毁其会话。实际使用了打印机 Mod，但没有在走位中保持自动打印。

新版宿主 `2026.10.15.2` 在现场加载的整个施工模型只有一个高度、且已开启自动走位时，平面移动保持同一个原生打印机会话；抵达站位后仍会补完附近可放方块。走动时仅让无状态属性、非下落、非方块实体的完整立方体成为打印候选。多层工程、垂直移动、复杂方块或需要朝向的操作继续按原来的站位逻辑处理。实际物品选择与放置全部由已安装的 Litematica Printer 完成。

走位仍核对实际身体碰撞、选中的原投影与施工批次。已排队的真实点击若会在下一步离开4.05格保守距离，或该动作涉及朝向/潜行，就保持悬停，让原打印队列完成；不会取消服务器未确认的动作来继续走。未知服务器确认的超时保护不变。手动操作、防御、界面暂停、重规划与结束仍释放按键并暂停或关闭打印机。

当前26.2原生打印机3.2.2的 `GeneralPlacementGuide` 对普通立方体不要求朝向；`PrepareAction` 在需要朝向时发送正常位置/朝向数据。未修改第三方打印机文件或伪造放置结果。

验证：项目指定的 `test jar verifyRuntimeEngineJar --offline` 全部通过，1988项Java检查无失败。新增几何回归覆盖边走边等确认、向点击点靠近可继续、向相反方向超过距离时停止、垂直腿及无效运动拒绝；宿主接线检查确认碰撞和点击距离门槛在移动前执行，复杂方块和服务器确认路径保留。

该修改涉及 `ProfessionalPrinter` 与 `ProjectionBuildJob` 宿主类，发布范围比较确认需要完整重启，不能仅热更导航引擎。已构建候选包，安装与实机连续打印验收尚未完成。不能将1988项检查当作已经在游戏启用或效率已提升的证明。
