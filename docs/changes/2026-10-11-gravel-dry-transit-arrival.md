# 沙砾海面航段复用精确空气导航

实机海床搜索曾在目标 X 两侧约 8 格的位置来回移动，日志持续出现新目标，但同一轮实际收益仍为 0/8。原 `GravelCollector.navigate` 使用普通导航，没有请求材料空气导航的刹停及稳定到达确认。

仅在角色已在水面上方、目标不低于返气高度，并且下一阶段为 `SETTLE_HIGH`、`SETTLE_SURFACE`、`PARK` 或 `REFILL` 时，复用既有原生 `air_only` 导航，使用 0.25 格到达精度。原生完整扫掠体积、区块、碰撞和危险方块检查继续决定是否允许移动。水下返气、下潜、近地站位、挖掘与拾取保持原流程。

主包版本 2026.10.11.1；引擎仍为 1.7.96。JDK 25 下 `test jar verifyRuntimeEngineJar --offline` 通过，新增策略检查覆盖海面航段、到达高度偏差、水下与低身体位置拒绝，以及下潜／采矿／拾取阶段不进入空气导航。

主包变化需要游戏完整重启。构建成功不代表安装或实机验收；实际安装和后续采集回执记录在当前任务目录。
