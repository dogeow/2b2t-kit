# 安全退出后等待玩家自行上线

用户澄清：正常可处理的受伤允许防御和恢复；对于无法处理、卡住持续掉血，或 Meteor/Kit 达到现有安全阈值而退出的情况，不再自动登录或自动恢复，等待玩家自行上线操作。

此前误解为“任意轻伤立即退出”的原生策略已关闭；相关新增引擎代码已撤回，正常引擎1.8.1重新构建校验完成。游戏内已在空闲控制点热恢复正常引擎1.8.1，原生回执确认 generation 2，未重启游戏。

- `health_exit_watch.py` 仅观察当前目标的受伤及安全退出证据，不发送退出、重连或游戏输入。正常轻伤、恢复、人工操作与其他世界均有回归覆盖。
- 安全锁已触发，或自动任务在尚未恢复的受伤状态下实际下线时，保留健康锁并设置助手控制锁；健康锁由现有游戏内确认流程处理，助手仍须获得明确的新接管授权。
- `game_connection_cli.connect` 在发送连接请求前检查健康锁与助手控制锁，避免原生健康锁已被人工确认后，助手又自行重新接手。
