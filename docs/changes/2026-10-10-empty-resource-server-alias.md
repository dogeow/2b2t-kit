# 空资源发现别名

同一服务器的不带端口橡木记录已有107个历史分区，`:25565`别名仅有0分区的空发现占位。旧规则比较整个JSON，空占位的进度字段和文件路径不同也会阻止正常采集。

现在只识别明确的空发现外壳：没有分区、航线、历史、扩展或未知字段，进度计数为0。存在一份或多份完全一致的非空记录时，可保留其全部内容并迁移空别名。所有原文件先逐字节归档，保存SHA256和协调记录；原观察与航线暂停不合并、不删除。

非空记录彼此不一致、空分区附带暂停/未知元数据、或者进度非零时继续拒绝，原件保持不变。相关原测试130项及新增4项通过；安装后仍需核对真实归档和采集结果，不能把空占位迁移视为木材入包。
