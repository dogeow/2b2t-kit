# 小区域连通目标的打印窗口

旧工作副本仅将开窗前已有直接支撑的目标放入掩码。同一 4×4 区域中，后续目标虽然能借助本窗口前一步的新方块获得支撑，仍要重新扫描、安装掩码和启动打印。

`projection_patch_plan.connected_mask` 从当前完整局部场景和冻结图纸目标中选择一个有实际支撑根的连通前缀。每个后续目标依赖真实已有支撑或前面已纳入的同区域目标；按实际库存裁剪前缀不会移除全部支撑根。范围最多 4×4、16 格，排除未知或尚待验收位置，不能跨区连接孤立目标。该返回值只是一份施工计划，每一步仍由正常原生打印器读取实际世界、选择实际锚点、发送交互并等待服务器回执；没有启用 AirPlace，也没有把后续目标当作已经存在的方块。
