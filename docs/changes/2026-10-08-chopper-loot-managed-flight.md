# 修复砍树后飞行拾取卡住

实机1.9.51日志中，拾取木棍时目标约2.47格外，角色实际flying=true，但canopyFlight=false，旧逻辑沿地面行走方向持续按前进，100拍无进展后放弃。低处树苗也重复同类停滞；74/85高度附近还有约0.025格的脚底碰撞穿插。

宿主2026.10.8.1、砍树器1.9.52改为使用Kit现有BuildNavigation寻找实际可拾取身体位置。拾取借用受控Meteor Flight设置，沿六邻接路径逐轴移动，不走与执行方式不一致的斜线捷径。每步重新检查服务器已加载区块、实际身体扫掠、实体碰撞和液体/火/蛛网/细雪；30拍真实位置无进展或路径变化时悬停，最多重规划两次。没有安全通道则保持位置，不用持续前进撞墙。

拾取判断按真实拾取身体范围，悬在物品上方一格仍会下降。只对脚底不超过0.08格的薄层穿插允许经终点碰撞验证的小幅上升，最多两次；真实墙体和未知区块不享受此处理。停止、界面或防护接管时释放自身飞行控制，恢复仍属于本功能的临时设置；自身启用飞行且仅离安全地面不超过0.35格时可正常落地关闭，否则保持安全飞行。补种返回也走已验证站位和现有平台导航。

实体消失、合并或卸载不再直接计为拾取，计数取同组件物品在背包中的真实增量。暂停飞行只松移动键，不重置树叶挖掘进度。

1853项Java回归、主包构建与外部引擎校验通过，包含实机坐标拾取范围、下降范围、薄层穿插、障碍绕行、单轴路径、拾取计数及运行接线检查。主包改动须重启游戏，API3及外部引擎1.7.86不变。安装和实机加载、运行验证分别在本轮工作记录中确认，离线回归不等于实机回收完成。
