# 地图与登记工位的高差不再触发横向折线

原地图直线入口只接受两端高差不超过 8 格，且两端至少比图面高 8 格。从图面附近的施工站位返回 Y85 的登记工位接近点时，这两个条件会拒绝直线入口，随后通用材料导航先沿 X、再沿 Z 到达工位。原条件把高度处理和水平路线耦合，导致本可直飞的返程绕路。

地图与已登记泥工位、工作台或仓储接近点之间，现在先在起点垂直升至较高端的高度（至少图面上方 8 格），再沿两点的水平连线飞行，需要下降时只在目标 XZ 上下降。`keep_cruise=True` 保持巡航高度。起始和目标高度仍须至少在图面上方 2 格，其他未登记路线继续使用原导航。

全部航段继续使用原生 `navigate(air_only=True)`、到达稳定确认、当前世界与控制检查。每段至多 48 格，水平段保留保守体积上限 8000，原生仍独立检查 8192 格体积上限、实体碰撞、区块和危险方块。起飞或任何航段拒绝后不发送后续航段，不回退重放未知导航。

115 项相关 Python 检查通过，覆盖地图与登记工位的原地起飞、共线航段、目标处下降、巡航保留、起飞拒绝和登记边界。当前实机断线，旧等待进程已结束，原施工和加工回执保留。本改动尚未完成新的实机往返验证；此前四段共线航行的证据只对应原高空入口。
