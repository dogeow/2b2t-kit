# 原位黏土生产的溺尸与自长草恢复

64黏土批次实际收取60球、回填14床后，取水的原生“健康空闲托管”准入检查拒绝发送。宽范围实体扫描确认取水点下方有一只溺尸。已通过正常敌对生物专用KillAura和水面上方飞行接近清除，血量保持20，被围住的僵尸猪灵未攻击。

`bottle_source_guard` 仅接受当前请求、世界、任务匹配且明确在发送前被拒绝的 `bottle_fill`。原库存保持不变、无在途/未知请求、满血、飞行、PvE和KillAura均有效时，才扫描原生防护包围盒。只处理近处、可见、未命名溺尸，普通剑和正常导航，25秒内监测健康；重新确认包围盒为空后允许一个新的取水请求。其它生物、未知结果、血量或控制变化均不进入恢复，不关闭原生防护。
