# 已脱险后的余火等待

主包 `2026.10.29.7` 增加 `safe_residual_fire_wait_protocol=1`，按用户明确要求区分“仍站在危险中”和“已飞离危险、身上尚有余火”。宿主判断需重启生效，引擎版本保持不变。

只有当前 PvE 物资/施工保护、近期已观察到怪物攻击、仅剩 `on_fire` 伤害、血量至少18且不低于最大血量80%、饱食度至少18，才考虑等待。当前身体必须无碰撞、周边为服务器已加载区块，且不在水/岩浆或邻近火、岩浆块、仙人掌、点燃的营火等实际危险中。

判断还排除可近身的敌对生物、苦力怕、仍在有效范围内且可见的远程怪物，以及正在飞向玩家的投射物。骷髅系使用本机官方26.2类中15格弓目标射程加一格余量；其它远程怪物保留更大的防护范围。附近末影人正被玩家注视时也不等待。

符合条件后暂缓战斗、移动和打印，保持原物资租约、防护状态、已发送动作身份及回执。余火熄灭后让现有进食恢复协调器回血，恢复满血后再继续。一次余火最多等待20秒，不因自然回血反复重开同一次等待。

出现新危险、血量或食物不足、界面/人工接管、世界改变或不支持战斗暂停时，取消这一例外，保留原环境伤害和低血量撤离逻辑。不会自动解除已经触发的安全离线锁，也不回放未知动作。

状态由 `residual_fire_wait` 给出，防护说明显示“安全高处等待余火熄灭”或“余火已灭，进食恢复后继续”。策略测试覆盖高血量反复余火、回血、未知点燃、真实火源/来袭威胁、低血量、时间倒退和等待上限；真实受伤场景不作主动引伤测试。
