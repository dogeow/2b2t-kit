# Kit 自动投影施工循环

沿用 Kit「自动补齐材料并建造」页面及「自动补齐并建造」按钮。启动后，现有后台任务持续处理当前锁定投影，并保存每批动作和回执；不需要逐批编写或运行临时脚本。

本次接入的流程：

1. 有施工材料，但目标被可识别的干燥自然地形占用时，先进入安全清障批次。
2. 原生挖掘序列及服务器方块更新确认后，回收已观察的掉落物并刷新完整投影审计。
3. 任务器自动继续打印，再按实际库存和新审计决定下一批清障、补料或制作。
4. 普通清障阶段保留当前位置，不先绕出投影再重新进入。打印仍使用原有站位和路径检查。

已有暂停/继续、玩家接管、取消、断点记录和运行时限继续生效。每个后台任务最多运行2小时、256批操作；安全锁不自动解除，断线不自动重连，未知动作不自动重放。

Kit 后台任务运行或收尾期间，临时材料控制器会拒绝抢占；后台自己的客户端凭任务编号继续复用原控制权。

清障进展不能仅靠背包变化或「已执行」回执判断。任务器要求原坐标确为自然占位、原生序列与服务器确认匹配，并由更新后的完整同范围审计证明占位已消失。旧未知记录在同一服务器与维度继续保护原坐标，切换投影或重连不会取消保护。

范围：本次先接通已有干燥自然清障能力。临水检修口、原水源操作、矿车等实体安装及农场自然产出验收仍需相应专用流程，不能将「投影方块任务完成」当作整座农场验收完成。遇到不支持或无法安全到达的情况，会保留现场并交回处理。

施工若意外潜入水下，后台立即暂停本批，核对同一控制权下当前身体所在列。仅当完整扫描证明 12 格内有普通水/空气组成的垂直退路、生命和氧气足够时，登记原生返气路线并正常飞回干燥处；不穿过顶棚，不挖逃生孔。退路不成立或氧气不足时请求安全退出，并保留新的健康锁。手动接管或菜单开启时不执行换气或退出。未知移动和放置不会重试，换气也不增加施工完成数。

若头已在水面上、脚仍在流水格内，空气退出规划也不能把该格当作空气。后台先完整扫描当前身体列，确认普通水上方有包含额外头部余量的干燥空间，再用一次原生普通移动同列抬升至干燥层以上半格。实际脚部离水、生命和氧气均确认后，重新扫描并规划退出；不沿用旧的湿起点。移动未知时保留原请求，不重试抬升。

普通地形掉落合并为 2–64 个时，拾取修正也复用邻近空气站位。只有原拾取已明确返回“到达但未确认入包”、同一 UUID 与物品堆仍可见、后续完整扫描在移动前发现阻挡时才重新选站位；泥径等碰撞格不会被当作空气。仍须实际库存增加及掉落物状态证明拾取，不能重新开采、重放未知移动或重复原拾取请求。

泥土、圆石、石头、煤、沙和沙砾若收到明确的默认拾取站位不可达回执，也可直接改用同一套邻近空气站位。仍核对原请求、当前世界/控制版本、同一 UUID、完整物品堆及未变化的库存；在途或未知动作不允许进入这条分支，装备等其它物品不由此扩大拾取范围。

宿主另有液体候选保护：Kit 持有普通打印器时，候选阶段拒绝水和岩浆，排队阶段再次阻止水桶动作；非 Kit 持有的手动打印模式保持原行为。液体属于最终建造要求，仍由独立的受控放水流程补齐，不会从整塔验收中删除。该宿主保护需要完整重启，不能仅靠 Python 后台包更新生效。

运行时导航另检查低空站位下方三格的未隔离热源。已确认的干燥完整方块或顶半台阶可隔开更低热源，近身接触危险和未加载区域仍拒绝通行。地板目标还允许正上方第三格的施工站位，候选仍受原有 4.15 格眼部距离限制；不通过降低避热检查来强行找到路线。这些引擎规则可热更新，离线通过后仍需现场核验。

改动位于 Python 后台任务器；更新已安装的材料后台包后生效，不需要重启 Minecraft。游戏内入口、原生移动/采集/打印器均沿用现有 Kit 功能。
