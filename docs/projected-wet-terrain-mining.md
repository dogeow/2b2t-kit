# 投影内临水自然地形清障

宿主版本 2026.10.28.5；状态能力 `projected_wet_terrain_mining_protocol=1`。
此入口用于先清理投影内自然地形，再补放蓝图方块。并非水下挖掘：玩家必须始终处于干燥、非着火的健康站位。

沿用 `mine_block`、材料租约、世界/控制版本和普通单方块挖掘确认机制。新增参数：

- `projected_wet_terrain: true`，严格布尔值，默认关闭。
- `placement_key`：当前锁定投影的完整键。
- `expected_goal_state`：该格投影中精确方块状态。
- `expected_tool_slot`：当前已选工具的快捷栏槽，整数。
- `expected_neighbors`：最新完整扫描的六向精确状态，键为 `down/up/north/south/east/west`，不能缺省或多传方向。

原有 `pos/face/expected_state` 仍需使用现场实测值。目标只允许泥土、草方块、石头和黏土；蓝图目标需属于实现中的建筑材料白名单。源水、矿石、成品建筑块、容器及当前脚下承重块不能借此拆除。目标必须在已加载服务端区块和当前可见投影层内；邻格存在容器或非水液体时拒绝。

生命至少19、饱食度至少18；根据地形使用有耐久余量的镐或铲，保持所选槽。普通材料所有权、防护、人工接管和未知请求规则全部保留。不能与其它挖掘例外组合。

挖掘开始前六个邻格必须逐一符合观察值。开始后只允许本次移除引起的空气/流水转为水；原有水源及含水方块仍必须精确保留。每个挖掘 tick 重新验证。任何停止或未知回执均保留原请求，不再次开采。

成功仍要求普通挖掘的当前连接服务器方块更新和原生序列确认。预测空气不算成功，之后还应检查材料回收、相邻水源和补放方块。编译与单元测试不等于实际游戏验收。
