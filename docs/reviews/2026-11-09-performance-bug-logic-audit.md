### 3.1 已验证或文档量化的优化（仍适用）

| 机制 | 效果（来源） |
|------|----------------|

| 10-17 死代码/重复类删除 | 净 **-322** 行生产代码；Java 2056 测试仍 0 失败（`validation.json`） |
| 测试去重（18） | 消除 18 次重复执行同一用例（审计 18） |

### 3.2 新增或加剧的性能压力

1. **`AutomationBridge`（~4869 行）**  
   单类承载材料任务、巡航、连接策略、打印等多路回调；任何 tick 内同步工作拉长都会放大 **主线程占用** 与 **状态耦合**。

2. **`village_queue.py`（~2252 行）**  
   村庄供料/排队与后端交互密集；典型模式为 `status()` / `checkpoint()` + 短 `sleep`，这些等待会产生轮询开销，现有材料没有证明该开销随队列深度上升。

3. **`material_jobs_backend.py`（~2279 行，13 处 `while True`）**  
   与 10 月相比体量略增；轮询间隔多为 0.05–0.25s，属有意权衡，分支集中增加审查成本，单凭文件大小无法判断解释器缓存局部性或耗时。

4. **大型 JSON 测试夹具**（如 `up-bubble-column.json`、`consumed-merchant-quote.json`）  
   示例夹具约 17 KiB 与 23 KiB，由对应测试读取。历史全量耗时不能归因于这些夹具，未测量其占比。

5. **`integrations/harness2`**  
   集成已于 10-27 移除。历史 `python_full_seconds` 是测试全量用时，无法作为当前 Harness² 的开销证据。

6. **聊天翻译路径**  
   `TranslationClient` / 网络 I/O（若实机启用）属于 **异步边界**；需与材料租约/界面暂停交互，错误配置可能导致不必要重试（未见统一退避文档）。

### 3.3 性能相关建议（仅报告，不实施）

- 对 **村庄队列 + AutomationBridge** 做 tick 预算或抽样 profiling（游戏内 `WorkHud` / 日志时间戳已有部分基础）。  
- 全量测试拆分：**固定离线子集**（`check_offline.py` 1907 项）与 **每周全量**（4208 项）分层，避免 Nov 6 之后无记录的回归空洞。  
- 先测量当前 fixture 的运行时间占比，再决定是否调整门禁。

## 5. 逻辑错误与契约风险

### 5.1 控制_revision 与 Handoff（`material_client.py`）

典型守卫（约 L288）：

```text
manual_movement  OR  (revision 不在允许集合 AND 非 native_stop AND 非 owned_terminal AND 非 owned_logout)
```

Python 中 **`and` 优先于 `or`**，语义为：手动移动立即 Handoff；否则仅在「revision 异常且不具备终端例外」时 Handoff。与注释中「native 超时双 revision 跳跃」场景一致 — **属有意逻辑，非运算符笔误**。

同类模式广泛分布于 `material_shutdown`、`navigation_watch.owned_flight`、`village_queue` 租约校验 — **一致性较好**。

### 5.2 已修复的逻辑类错误（非单纯崩溃 Bug）

| 类型 | 说明 |
|------|------|
| **预留 vs 执行不一致** | 仓库/末影箱取料计划预留格子，transfer 未遵守 → 7f1a485 |
| **管线注册互斥** | 同一物品双路径注册 → 闪长岩拆分 |
| **测试替身协议漂移** | 旧 `native_inflight`/熔炉/容量字段 → 大量 test 与 7f1a485 对齐 |
| **打印漏斗** | 预测状态与最终供电确认混用 → 6a06e71 分层 |
| **熔岩输入** | 同时按下飞行上升键（jump）与下降键（sneak）导致输入冲突 → `MagmaFlightEscape` |

### 5.3 残余逻辑/复杂度风险

1. **`village_queue.py` 体量**  
   状态与副作用集中，边界条件（重连、取消、部分配置读）依赖长链 `if`；**单点回归遗漏概率高于模块化后端**。

2. **`AutomationBridge` 上帝类**  
   新行为默认从桥接层接入，易出现 **隐式顺序依赖**（例如连接策略 vs 材料暂停 vs 打印）。

3. **双语文本/翻译**  
   新增 `mcbilingual.mixins.json` 与聊天客户端；与材料 **界面暂停** 交互路径需实机矩阵验证。

4. **Harness 与生产路径分歧**  
   Harness² 属于已移除的历史集成。当前离线测试与 26.2 实机验收仍应分别记录。

5. **验证空窗**  
   最近机器可读全绿记录为 **2026-10-17**（`docs/audits/fixes-2026-10-17/validation.json`：Java 2056，Python full 4208）。HEAD 为 **2026-11-06**，中间 **~20 天 / 数十提交** 无同等级 JSON 快照附在仓库内。

6. **地图画终态**
