# 岩浆低空路线与自动潜行

当前飞行设置下已两次记录角色低空经过岩浆列时收到hot_floor伤害。局部空气路线现在排除岩浆上方三格；若中间已有观察到的完整安全方块遮挡，则保留通行。扫描向下多取一格，避免只看身体位置而漏掉脚下危险。

引擎1.8.38复用当前Meteor的Sneak模块Packet模式：独立PvE防护开启、挖矿引擎未运行且角色脚下三格内有岩浆时，临时借用原先关闭的模块。Packet模式经当前26.2-35实际JAR与Mixin核对，不按住飞行下降键。模块自身doPacket不适用时不声称保护生效。

已有用户启用的潜行设置不改动。用户在借用期间切换模式或关闭模块，交还所有权；离开当前危险范围、停止防护或停止引擎时，只恢复仍由本次借用持有的设置。激活失败也恢复原模式。原生低血、未知持续伤害、安全锁和恢复确认规则均保持原样。

路线脚本已热更新；引擎JAR可热加载，无需更换主包。目前为安全离线状态，仅已备份并部署候选文件，尚未执行runtime_reload，实机效果待恢复后核验。诊断文件guard-magma-sneak-state.json只标记模块作用条件和借用状态，不是安全锁恢复授权。
