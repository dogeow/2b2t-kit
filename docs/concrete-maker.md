# 混凝土制作

入口：按 U → 生产 → 混凝土制作。也可以在工具箱搜索“混凝土”或“concrete”。

1. 在漏斗或固定支撑旁准备好水，含水树叶也可使用。
2. 主手拿需要制作的混凝土粉末，准星对准漏斗顶面或其它放置面。
3. 打开功能页面，填写制作数量；0 表示持续循环。
4. 点“开始制作”，角色会在原位放粉末、等待硬化、用镐挖掉并继续放置。

打开菜单暂停，关闭菜单继续；点“停止制作”或紧急停止键结束。移动离开固定位置、缺同色粉末、缺可用镐、耐久不足、支撑改变、目标出现其它方块或服务器确认超时都会停止。

自动使用背包同色粉末；工具选择遵守 Meteor AutoTool 的黑白名单和更严格的耐久保护。成品由现有漏斗装置收集。制作数量依据服务器确认的混凝土放置与挖除计数。

1.9.13 在暂停恢复测试中出现完成数与成品相差 1 的情况；1.9.14 只在收到服务器确认混凝土和挖除更新后计数，监听单块与区段更新包。
