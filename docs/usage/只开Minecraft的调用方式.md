# 只开 Minecraft 的调用方式

当前入口是 HMCL 的 **26.2** 实例（旧 26.1.2 实例保留用于回退）。
实际游戏目录是 `/Applications/.minecraft/versions/26.2`，使用 HMCL 的版本隔离；
正在运行的 Kit 版本可用 `python3 decision-runtime/kit_cli.py status` 查看。

进入服务器后，按 **U**，在左侧导航栏的“生产”分组里选择：

- **自动砍树**：原生砍伐、拾取和补种。
- **材料任务**：选择物品及背包目标数量，点击“开始获取材料”。
- **投影建造**：使用已经加载并正确放置的 Litematica 投影。
- 投影材料模式提供“自动补齐并建造”；它仍依赖已登记的真实物资来源与实际支持的采集能力，不能保证任意材料都能自动获得。

这些入口不需要打开 ChatGPT 或其它模型界面。原生游戏功能直接在 Minecraft
内执行；材料流水线可能由 Kit 启动一个轻量的后台 Python 工作进程，不需要
另开终端窗口。缺少来源或能力时会报告具体缺口。

## 内存设置

这台机器为 18 GiB 内存。已将当前实例的 Java 堆上限设为 **3072 MiB**；保留
用户设置的 **60 FPS、模拟距离 5、渲染距离 5**。堆上限不等于游戏进程的总内存，
原生资源和图形内存仍会占用额外空间。
