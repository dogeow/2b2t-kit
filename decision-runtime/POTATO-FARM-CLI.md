# 土豆田命令

使用已安装的 Kit worker，直接调用接口，不依赖 UI、按键或 AI 循环。当前为已装水的半径1或2土豆田种植工序；不会自动补水、收获或烹饪。中心坐标是水源方块所在的地面层。

```bash
"/Users/sam/Library/Application Support/MinecraftDecisions/venv/bin/python" -B \
  /Applications/.minecraft/versions/26.1.2/config/twob2tkit/material-worker/kit_cli.py \
  farm plant --center 761021 63 797869 --radius 2 --max-cells 24
```

入口复用正常锄头/土豆交互和原生材料防护租约。默认只接近32格内田地，先核对中心源水和完整竖直空气列，再使用原生 air_only 移动；`--no-move` 只跳过接近，正常收尾仍可能升到安全处。外部 `--out` 可指定已有该田地的账本目录；一旦登记，不能更换目录绕过未知动作。

所有待种格必须有实际足够的土豆、可用普通锄头、真实光照和干燥底层。每格保留两次后续真实方块/库存变化，不能冒称通用 interact 有专用服务端 ACK。返回 FARM_BATCH 是已确认的小批完成，保留进度；同一会话继续只处理未确认格。未知动作、换世界、手动接管或受伤保留记录并停止普通导航；不自动重连、解锁或重放。跨世界的旧账本需要显式核验恢复，当前入口不会自动重新绑定。
